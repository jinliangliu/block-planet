# 开发日志 2026-09-25

## 三十、死亡 R.I.P 墓碑表现

**需求**：玩家角色死亡后先有 RIP 墓碑效果，再复活。

**实现**：
- 新增 `scripts/world/tombstone.gd`：灰色两段石碑 + R.I.P 铭文 + 小白花 +
  落碑尘土，立在死亡点**身前 0.8 米**（与尸体错开）；碑面 +Z 转向凭吊者；
  停留 45 秒后缩小消散（防无限堆积）。
- 玩家死亡流程改为「停顿 2.2 秒再复活」：`_dead` 冻结物理/受击/交互，
  `SceneTreeTimer` 到点后回出生点复活（防卡死脱困仍走瞬间重生，不受影响）。
- HUD 新增 RIP 覆盖层：暗幕 + 🕯 + R.I.P + 「即将回到出生点」，随停顿
  淡入淡出，`MOUSE_FILTER_IGNORE` 不挡操作。

**验证**：新增 `tests/death_probe`（10 项：墓碑立位/冻结/免击/复活回满/
三墓碑并存）；stuck_probe 全绿（瞬间脱困保留）；life_probe 386/386。
视觉取证：白昼独立场景确认铭文朝向（Label3D 贴 +Z 面，spawn 转向凭吊者），
取证后按惯例删除一次性探针。

**教训**：截图探针访问 HUD 节点名为 `UI` 不是 `HUD`；开局地图选择器需
`hud.close_map_selector()` + `GameState.needs_region_pick = false` 复位。

## 二十九、村民手臂 + 床配方调整

**村民没有手臂**：`_build_villager_like`（村民/掠夺者共用）只拼了长袍+头+
鼻子+眼睛。补上手臂并按身份区分：村民经典**抱臂站姿**（肩部前伸上臂 +
下垂小臂 + 胸前交叠横臂），掠夺者**双臂垂在身侧、末端露肤色手**。
窗口截图取证确认造型正确后按惯例删除一次性探针。

**床配方**：按用户要求从 3 羊毛+3 木板 调整为 **2 羊毛 + 3 木板**
（床本身已有：放置后夜晚右键直接跳到清晨，无需新增）。

**回归加固**：life_probe 新增断言「村民模型有手臂（网格 ≥ 10）」，防止
造型回退。期间踩了 GDScript 值传递老坑：递归计数函数用 `int` 出参，
`out += 1` 改的是拷贝——改成返回值后通过。

**验证**：life_probe **386/386**（含新断言）；mob_probe 全绿。

## 二十八、木镰刀收割修复（D-027）

**现象**：用户报「木镰刀没法收割水稻、小麦等各种农作物」。

**排查**：数据层全部正常（作物硬度 0.1、`EFFECTIVE_TOOL` 已挂 sickle、
无等级门槛、`drop_count_for` 镰刀加成在）。写 `tests/crop_raycast_probe`
走**真实左键链路**复现（此前 M8.6 的探针全直调 `_finish_break`，从没验证过
射线），一跑就抓到每帧脚本错误。

**根因（两个叠加）**：
1. 体素命中的字典没有 `collider` 键，`_update_breaking`、`_try_attack_mob`、
   `_interact_village` 三处 `hit["collider"]` 直接 KeyError，破坏逻辑中断；
2. 旧体素射线 0.05 步进采样，命中点落在作物格内部，与脚下耕地顶面的物理
   命中比近永远输——瞄准作物实际割到的是耕地。

**修复**：
- `World.raycast_blocks` 重写为 Amanatides & Woo DDA，返回精确进入距离
  `distance`；`_raycast_target` 比近规则改为「体素进入不晚于物理命中即取
  体素」（共用边界时作物优先）。
- 三处 `hit["collider"]` → `hit.get("collider")`。
- 物理射线 `query.exclude` 排除玩家自身胶囊体（第三人称自挡射线的隐患）。

**验证**：crop_raycast_probe 全绿（俯视瞄准 → 命中作物 → 割下 → 背包
小麦 +4）；life_probe 385/385；interaction_probe 全绿。

**教训**：交互修复必须走真实输入链路验证，直调内部函数会漏掉整段链路。
