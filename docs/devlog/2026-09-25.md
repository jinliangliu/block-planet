# 开发日志 2026-09-25

## 二十八、木镰刀收割修复（D-027）

**现象**：用户报「木镰刀没法收割水稻、小麦等各种农作物」。

**排查**：数据层全部正常（作物硬度 0.1、`EFFECTIVE_TOOL` 已挂 sickle、
无等级门槛、`drop_count_for` 镰刀加成在）。写 `tests/crop_raycast_probe`
走**真实左键链路**复现（此前 M8.6 的探针全直调 `_finish_break`，从没验证过
射线），一跑就抓到每帧脚本错误。

**根因（两个叠加）**：
1. 体素命中的字典没有 `collider` 键，`_update_breaking`、`_try_attack_mob`、
   `_interact_village` 三处 `hit["collider"]` 直接 KeyError，破坏逻辑中断；
2. 旧体素射线 0.05 步进采样，命中点落在作物格内部，与脚下耕地顶面的物理
   命中比近永远输——瞄准作物实际割到的是耕地。

**修复**：
- `World.raycast_blocks` 重写为 Amanatides & Woo DDA，返回精确进入距离
  `distance`；`_raycast_target` 比近规则改为「体素进入不晚于物理命中即取
  体素」（共用边界时作物优先）。
- 三处 `hit["collider"]` → `hit.get("collider")`。
- 物理射线 `query.exclude` 排除玩家自身胶囊体（第三人称自挡射线的隐患）。

**验证**：crop_raycast_probe 全绿（俯视瞄准 → 命中作物 → 割下 → 背包
小麦 +4）；life_probe 385/385；interaction_probe 全绿。

**教训**：交互修复必须走真实输入链路验证，直调内部函数会漏掉整段链路。
