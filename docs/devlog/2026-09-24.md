## 五、M6.11 地图选择器与区域化世界（当日最大单块）

**3D 地球**

- `region_atlas.gd`：36×72 等距圆柱掩码（5° 一格）描述七大洲四大洋；掩码外按经纬度归入四大洋
- `map_globe.gd`：`SurfaceTool` 逐格生成顶点色球面；**拾取用射线-球面解析求交**，命中点经 `dir_to_lat_lon` 还原经纬度——与建网格的 `lat_lon_to_dir` **互为逆函数**，因此「屏幕上看到的色块」与「点中的区域」严格一致
- `map_selector.gd`：三页模态（地球 / 介绍 / 加载），`SubViewport` 独立世界渲染球体

**区域化世界生成**：每区独立种子 + 地形基准高度与起伏 + 地表材质分界 + 树木密度 + 天空色调 + 白天/夜晚加权生成表。11 个区域（太平洋/大西洋/印度洋/北冰洋/亚洲/欧洲/非洲/北美洲/南美洲/大洋洲/南极洲）。

**核心架构决策**：区域切换走 **`reload_current_scene()`**——区块、村庄、生物、HUD 全部随场景重建，彻底避免手工清理世界状态；区域 ID 与背包经 `GameState` 跨重载携带。键位调整：M 键改为 `toggle_map`，**模式切换改 G**。

**踩坑**：

- 手写 72 列矩形容差极易数错 → 改用 Python 按「(字符, 起, 止) 列表」生成并**逐行校验长度 + 打印 ASCII 图目视**
- `LAND_MASK[row].substr()` 因常量数组元素是 `Variant` 会报「Cannot infer the type」→ 须显式 `var ch: String`
- 底部锚定 `Control` 的带区高度小于 `GridContainer` 实际内容高度时会向下溢出被裁 → 修复图例溢出与提示重叠
- `SubViewport` 拾取两坑：`SubViewportContainer` 设 `MOUSE_FILTER_IGNORE` 后鼠标事件不转发进 SubViewport，`viewport.get_mouse_position()` 恒为 `(0,0)` → 须用控件 `get_global_mouse_position()` 减 `stage.get_global_rect().position` 换算；`Camera3D.project_ray_origin/normal` 接收**视口像素坐标**而非 NDC，传 NDC 会把射线打到视口左下角
- 区域名标签渐隐须**同步 `modulate.a` 与 `outline_modulate.a`**（描边 alpha 独立，不同步会残留黑块）

**地球 UI 三轮迭代**：图例改左侧竖列 → 两极加「北极/南极」`Label3D` 标记 → `DRAG_SPEED` 0.008 → 0.015。

**结果**：`life_probe` 157/157；主场景真实启动 150 帧无错误。

## 七、任务与成就系统（M6.12~M6.15）

**三层架构**：

```
Events 信号桥  →  ProgressManager（Autoload「Progress」）  →  QuestPanel（J 键）
```

- **Events**：补 `mob_killed` / `player_died` / `craft_done` / `smelt_done` 信号（`mob.gd` 死亡分支 1 行接入）
- **ProgressManager**：计数器 + 状态机 `ACTIVE → DONE → CLAIMED`；`claim` 只发信号不摸背包，奖励入包由 HUD 监听执行；`user://progress.json` 每次 `notify` 落盘
- **QuestPanel**：J 键模态冻结玩家，双页签（任务/成就）+ 进度条 + 领奖 + 内嵌问答区（**每答对 3 题自动发面包×2**）
- **Toast**：顶部居中 2.2 s 淡出

**内容**：8 环新手引导链（`prerequisite` 顺序解锁）+ 25 枚成就（五类分组）+ 25 题知识问答。

**踩坑**：

- `const` 数组内不能做 `"mined_%d" % WOOD` 运算 → 改用 `static var` 惰性构建
- `Array.pop_back()` 返回 `Variant`，警告即错误下须显式 `var x: int =` 
- **探针污染存档**：`life_probe` 阶段 L 备份 counters/states → 清空 → 测试 → 还原；被 SIGTERM 强杀的运行会把测试态留在 `user://progress.json`，收尾须删除

**结果**：`life_probe` **186/186**；smoke/mob/interaction/village/pyramid/physics 全绿。

5. **`render_probe` 不能加 `--headless`**——会永远卡在 `await RenderingServer.frame_post_draw`；`physics_probe` 无 PASS 行、只打诊断值，判绿要看 `PHYSICS_PROBE_DONE`。
