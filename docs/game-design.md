# Block Planet 游戏设计文档

> 本文档描述**已实现**的游戏设计，并单独标注**规划中**的部分。
> 撰写基准：2026-09-24 代码状态（M1~M8 已完成）。
> 代码是唯一事实来源；本文与代码不一致时以代码为准，并应回来修订本文。

---

## 1. 定位

**Block Planet** 是一款面向儿童的像素体素沙盒游戏。玩家以第一人称（可切换到第三人称）在一个由方块构成的世界里采集、建造、生存与探索，并可以通过 3D 地球在不同地理区域之间旅行。

- **一句话**：会带孩子环游世界的地理沙盒。
- **角色**：玩家形象为方块小人，默认姓名「小方块」。
- **引擎/平台**：Godot 4.6（Mobile 渲染器），GDScript 2.0；目标设备为中低端 Android 手机/平板，桌面端同样可玩。
- **形态**：单机离线。无联网、无联机、无排行榜、无云存档；不申请网络权限，仅申请本地存储权限。

### 1.1 目标用户

| 维度 | 设定 |
|------|------|
| 年龄段 | 约 6~12 岁，以及陪同的家长 |
| 识字水平 | 能读简单句；所有交互必须有图标/颜色冗余提示 |
| 操作能力 | 触屏为主，鼠标键盘为辅；不接受需要精确时序的操作 |

### 1.2 设计原则（红线）

1. **无恐怖、无血腥**。怪物一律「可爱化、小型化」（小僵尸/小骷髅/小蜘蛛）。死亡是被弹回出生点，不出现任何伤口、血液、骷髅尸体特写。
2. **不惩罚好奇心**。破坏不可逆的惩罚降到最低：掉落物直接进背包；保护动物不可伤害；矿石等级不足时给出**明确提示**而非无声失败。
3. **知识必须可验证**。所有探索内容（地理卡片、问答）的答案都能在游戏内的说明书或知识卡片中找到线索，不依赖外部资料。
4. **鼓励而非逼迫**。任务系统全部是正向目标，没有倒计时压力；没有失败结算界面。
5. **一个界面只教一件事**。每个面板（合成台/储物箱/说明书/任务）只承载一类操作。

## 2. 游戏模式

| 模式 | 状态 | 行为差异 |
|------|------|----------|
| **生存模式** | ✅ 已实现，默认模式 | 有生命/饥饿；方块需采集；有工具耐久；夜晚生成敌对生物；不能飞行 |
| **创造模式** | ✅ 已实现 | 无限方块、无敌、可飞行（双击空格）、饥饿不消耗；G 键切换 |
| **探索模式** | ✅ 已实现（M7.1 模式本体） | 生存机制照常（生命/饥饿/掉落/耐久），但不生成敌对生物、可飞行（双击空格）、G 键禁切创造；地图选择器地球页底部提供「生存 / 创造 / 探索」三选一，点选即时生效 |

模式切换：`G` 键 / 触屏「模式」按钮。模式通过 `GameState.set_mode()` 广播 `mode_changed` 信号，HUD、玩家控制器、生成器均订阅该信号，不存在各处自行读枚举的分叉。

## 3. 核心循环

```
   采集 ──▶ 合成 ──▶ 建造 ──▶ 生存 ──▶ 探索新区域
    ▲                                        │
    └──────────── 新材料 / 新工具 ◀───────────┘
```

1. **采集**：破坏方块（原木、石头、矿石、作物）获得资源；狩猎与垂钓获得食物与材料。
2. **合成**：合成台做工具/方块/食物；冶炼炉把矿石炼成锭。
3. **建造**：自由搭建房屋、金字塔、桥梁；储物箱收纳物资。
4. **生存**：管理生命与饥饿，夜晚躲避或反击敌对生物，饿了吃东西。
5. **探索**：按 M 打开 3D 地球，选择一个区域进入——那里的地形、植被、动物、天空色调全部不同。

**探索目标嵌在循环里**：每进入一个新区域，会通过加载页与知识卡片介绍该区域的地理特征；任务系统把「去村庄交易」「踏足新大陆」「炉火初燃」串成新手引导链，边玩边学。

## 4. 世界与区域

### 4.1 世界结构

- 区块尺寸 **16 × 64 × 16**，海平面固定 `y = 22`。
- 以玩家为中心流式加载/卸载（`LOAD_RADIUS = 2`），每帧加载 2 个区块，按到玩家的曼哈顿距离升序（脚下与前进方向优先）。
- 玩家修改过的方块记入 `_modified_data`，区块卸载后重载仍然保留——这是建造不丢的根基。
- 地形由 `FastNoiseLite` 生成：平原、丘陵、山脉、水面、树木、石层与矿脉。

### 4.2 11 个可进入区域（七大洲 + 四大洋）

| 区域 | 一句话 |
|------|--------|
| 太平洋 | 世界最大的海洋 |
| 大西洋 | 呈 S 形的第二大洋 |
| 印度洋 | 季风最典型的大洋 |
| 北冰洋 | 最小最浅的大洋，终年结冰 |
| 亚洲 | 面积最大的洲（默认区域，含雪线高峰与大熊猫） |
| 欧洲 | 海岸线最曲折的洲，林木最密 |
| 非洲 | 沙漠与热带草原 |
| 北美洲 | 山脉纵贯的大陆 |
| 南美洲 | 安第斯与亚马孙，雨林密度全图最高 |
| 大洋洲 | 荒漠与草原之洲 |
| 南极洲 | 冰盖与极昼极夜 |

**每个区域独立配置**（`RegionAtlas.REGIONS`）：

| 参数 | 作用 |
|------|------|
| `seed` | 本区独立随机种子，矿脉/树木/水体均可复现 |
| `base_height` / `amplitude` | 地形基准高度与起伏幅度 |
| `surface` / `surface_low` / `low_line` | 地表材质分界（如非洲：低地沙丘、高地草原；两极全雪） |
| `sub` / `sub_low` | 地表下三格的材质 |
| `tree_density` | 每列生成树的概率 |
| `sky` | 天空色调（乘算到天幕与环境光） |
| `passive` / `hostile` | 白天动物与夜晚敌对的加权生成表（北冰洋为空表，即「没有动物」） |

### 4.3 区域切换的实现

地图选择器 → 选定区域 → `GameState.set_region()` → `Main` 执行 `reload_current_scene()`。

- 区块、村庄、生物、HUD **全部随场景重建**，避免手工清理世界状态（这是本项目最重要的一条架构选择，见 `decisions.md` D-007）。
- 背包通过 `GameState.carried_inventory` 跨重载携带，切图不丢东西。

## 5. 方块与物品体系

### 5.1 方块（`BlockTypes.Block`，26 种）

- **自然**：草、泥土、石头、沙子、原木、树叶、水、雪
- **矿产**：铜矿石、锡矿石、铁矿石、金矿石
- **加工**：圆石、玻璃、羊毛、木板系（由原木合成）
- **功能**：储物箱、冶炼炉、酿灶台、耕地、小麦作物
- **水生植物**：水草、藻类、浮萍、荷叶、莲花

每种方块登记：显示名、短名、是否固体、是否透明、纹理瓦片、硬度、**有效工具类别**、**最低工具等级**。

### 5.2 物品（`ItemTypes`）

- **工具 26 件**：木/石/青铜/铁 各配 镐·斧·锹·镰（16 件）+ 银/金 镐·斧·锹（6 件）+ 木/铁鱼竿（2 件）+ 木/铁弓（2 件）。
- **材料**：铜/锡/青铜/铁/银/金/合金锭、水晶、碳棒、兽皮、羽毛、獠牙、箭、骨头、线、绿宝石、不死图腾。
- **食物**：生牛排（+8）、生鸡肉（+5）、生猪排（+6）、面包（+7）、生鱼、生虾、蟹肉。
- **堆叠上限**：100。工具不堆叠，按耐久独立记录。

## 6. 工具分级系统（M8.1）

### 6.1 四个等级

| 等级 | 材质 | 挖掘倍率 | 典型来源 |
|------|------|----------|----------|
| 1 | 木头 | 2.0 | 手搓 |
| 2 | 石头 | 4.0 | 手搓 |
| 3 | 青铜 | 6.5 | 冶炼（铜锭 + 锡锭） |
| 4 | 铁 | 9.0 | 冶炼（铁矿石） |
| — | 银 / 金 | 11.0 / 13.0 | 交易 / 冶炼（进阶变体，不占等级位） |

### 6.2 工具与场景的对应

- **镐** → 石头、矿石、圆石、冶炼炉
- **斧** → 原木、木头类
- **锹** → 泥土、沙子
- **镰** → 小麦、水草、藻类、浮萍（收割有额外产出加成）
- **鱼竿** → 捕捞鱼/虾/蟹
- **弓** → 远程狩猎与自卫

### 6.3 矿石等级门槛（`MIN_TIER`）

| 矿石 | 最低镐等级 | 提示语 |
|------|-----------|--------|
| 铜矿石 | 任意（含徒手） | — |
| 锡矿石 | 1 木镐 | 「需要石镐才能采到锡矿」 |
| 铁矿石 | 2 石镐 | 「需要青铜镐才能采到铁矿」 |
| 金矿石 | 3 青铜镐 | 「需要铁镐才能采到金矿」 |

等级不足时**方块照常被破坏，但不掉落**，并在左下角系统日志区播报明确提示——避免孩子「默默挖了半天什么都没有」的挫败。

**地层分布**（概率由确定性哈希决定，坐标级可复现）：

| 矿石 | 出现概率 | 深度限制 |
|------|---------|----------|
| 铜 | 2.5% | 全石层 |
| 锡 | 1.0% | 海平面 +2 以下 |
| 铁 | 1.0% | 海平面 −6 以下 |
| 金 | 0.4% | 海平面 −12 以下 |

**材料获取路径是挖矿与交易的混合**：铁/金靠挖矿，银/水晶/碳棒靠村民交易与闯关奖励。

## 7. 生物与生态

### 7.1 生物名录（22 种）

- **敌对（3）**：小僵尸、小骷髅（远程射箭）、小蜘蛛
- **凶狠中立（2）**：狼（夜晚与敌对同池生成）、掠夺者（白天驻守掠夺塔）
- **家畜（4）**：牛、羊、鸡、猪
- **水生物（5）**：鱼、虾、蟹、蜻蜓、青蛙
- **村民（1）**：大鼻子村民（永续被动，可交易）
- **保护动物（6）**：大熊猫、金丝猴、朱鹮、白头海雕、北极熊、袋鼠
- **新增（1）**：蝴蝶

### 7.2 生成规则

- **敌对生物**：夜晚在玩家周围生成（上限 8 只），出生点向上扫描真实落点，避开树干与建筑；白天全部清空。
- **被动动物**：白天在草地上生成（上限 6 只），白天不清空；撞墙换向，受击逃跑（反击名录中的先反击）。
- **水生物**：独立生成轨道（不与陆地上限互挤），按栖息地分派——大河中鱼潜游、蟹贴底爬行、虾游弋，池塘中蜻蜓悬停浮动、青蛙岸边间歇起跳。
- **区域加权**：每个区域有自己的白天/夜晚生成表。北冰洋白天为空表（只有风雪与脚印），亚洲额外有大熊猫/金丝猴/朱鹮，北美有白头海雕，大洋洲有袋鼠，北极圈有北极熊。
- **村庄 NPC** 由 `VillageBuilder` 直接挂在主场景，绕开生成器的昼夜清空与补货逻辑。

### 7.3 生长系统（M8.2）

每种动物有一条**成长阶段链**（`MOB_STAGES`），由**游戏天数**驱动推进，每过一个游戏日推进一个阶段：

| 生物 | 阶段链 |
|------|--------|
| 鸡 | 鸡蛋 → 小鸡 → 鸡 |
| 青蛙 | 蛙卵 → 蝌蚪 → 青蛙 |
| 蝴蝶 | 蝶卵 → 毛毛虫 → 茧 → 蝴蝶 |
| 鱼 | 鱼苗 → 小鱼 → 鱼 |
| 牛 / 羊 / 猪 | 幼崽 → 成体（两段，胎生） |

- **视觉**：按阶段整体缩放 + 卵/蝌蚪/毛毛虫/茧有专用小模型。
- **属性**：以成体为基准，按阶段倍率换算（生命、速度、掉落量）。基础值与当前值双记录，保证阶段切换反复调用无损。
- **掉落**：幼体掉落更少（如小鸡只掉羽毛），成体才产出主产物。
- **生成器默认以成体出现**，只有小概率抽中幼体，避免「出门全是宝宝」影响体验。
- **持久化**：生长阶段随存档保存（依赖 M7 SaveManager，规划中）。

### 7.4 保护动物（M8.2）

**名录**：大熊猫、金丝猴、朱鹮、白头海雕、北极熊、袋鼠，以及村民、蜻蜓、蝴蝶。

- 头顶名牌显示为**绿色**，与普通生物的白色、反击状态的红色区分。
- **无法被伤害**：攻击被拦截，只显示解释性提示（如「大熊猫是国家一级保护动物，请不要伤害它」）。
- 弓射出的箭命中保护动物同样免伤——保护是**跨武器一致**的。
- 设计意图：把「不能伤害珍稀动物」做成游戏机制而不是口头说教。

### 7.5 反击机制（M8.3）

北极熊与蟹受击后会进入**反击状态**（名牌变红），主动追击攻击者。这是给玩家的唯一「主动招惹有代价」的反馈，其余被动动物只会逃跑。

## 8. 狩猎与垂钓（M8.3 / M8.4）

### 8.1 狩猎规则引擎

`HuntRules` 用一张规则表回答「用这个工具打这只生物，会发生什么」：

| 猎物 | 所需工具 | 最低等级 | 基础伤害 |
|------|---------|---------|---------|
| 牛 / 羊 / 猪 / 鸡 / 小僵尸 / 小骷髅 / 小蜘蛛 | 斧 | 1 | 4 |
| 狼 / 掠夺者 | 斧 | 2 | 4 |
| 鱼 / 虾 / 蟹 / 蛙 | 鱼竿 | 1 | 5 / 4 |

- **工具不对**：伤害折半，并给出提示（教孩子「砍树用斧头，收麦用镰刀」）。
- **徒手**：基础伤害 1，明显低于正确工具，鼓励做工具而不是硬敲。
- **逐级掉落**：掉落按**物种 + 生长阶段**决定，成体产出主产物（生牛排/羊毛/生鸡肉/生猪排/兽皮/獠牙），幼体只有边角料。
- **工具耐久**：只有真正用到对应工具时才磨损。

### 8.2 弓箭（蓄力射击）

- 右键**按住蓄力**（0.15s 起效，1.2s 蓄满），松手射出；蓄力条显示在屏幕准星下方。
- 伤害随蓄力比例在 2~6 之间线性变化。
- 每射一箭消耗 1 支箭（合成一次得 4 支）。
- 与骷髅的箭共用 `ArrowProjectile` 实体，但分敌对/玩家两个模式，玩家箭命中保护动物与幼体**免伤**。

### 8.3 垂钓（抛竿 → 等待 → 咬钩 → 收竿）

- 手持鱼竿右键抛竿，浮标（红白相间）落到水面，钓线从浮标拉向相机。
- 等待 3~8 秒后浮标下沉（咬钩），有 1.6 秒**收竿窗口**。
- 窗口内收竿 → 按权重抽取战利品（几乎都是鱼虾，偶尔混进水草）；错过窗口 → 空手。
- 随时可以提前收竿，不会卡状态（安全兜底）。
- 钓到的鱼同时服务两条线：食物，以及「渔夫」成就。

## 9. 任务与成就系统

三层架构：**Events 信号桥 → ProgressManager（Autoload，计数器 + 状态机）→ HUD 任务面板**（J 键）。

### 9.1 结构

- **计数器**：`mined_<block_id>` / `crafted_<item_id>` / `killed_<mob_type>` / `mob_killed` / `placed_any` / `traded` / `regions_<id>` / `grown_*` 等。
- **状态机**：`LOCKED → ACTIVE → DONE → CLAIMED`。达成后需手动点「领取奖励」，强化正反馈。
- **目标类型**：`count`（计数达标）/ `regions`（踏足区域数）/ `distinct_mined`（挖掘过的方块种类）/ `quests_done`（已领任务数）。
- **持久化**：`user://progress.json`，每次计数变化即落盘，跨区域重载存活。

### 9.2 内容规模

| 类别 | 内容 |
|------|------|
| 新手任务链 | **8 环**，按 `prerequisite` 顺序解锁：动手采集 → 小小建筑师 → 初次合成 → 工具匠 → 以物易物 → 打开世界地图 → 踏足新大陆 → 炉火初燃 |
| 成就 | **25 枚**，五类分组：知识问答 / 生存技能 / 地图探索 / 游戏闯关 / 新手毕业 |
| 知识问答 | **25 题**，答对 3 题发面包 ×2 |

**新手链的设计意图**：8 环正好把「挖掘 → 建造 → 合成 → 工具 → 交易 → 地图 → 换区域 → 冶炼」这条完整主线走一遍，孩子在拿到「新手毕业」成就时已经掌握了全部基础操作。

**成就举例**：石器时代、点石成金、小小猎手、建筑师、环球冒险家（踏足全部 11 区域）、钢铁时代（合成铁镐）、收割好手（镰刀）、小小弓箭手、垂钓入门、牧场主、渔夫、勇者无畏、小小观察员（看动物长大 3 次）、孵化见证者（看鸡蛋孵出小鸡）、池塘里的秘密（蝌蚪变青蛙）、动物守护者（了解 3 种保护动物且未伤害）。

## 10. 探索目标

探索内容不是附加模块，而是**从世界结构里长出来的**。

| 学科 | 载体 | 具体形式 |
|------|------|----------|
| **地理** | 3D 地球 + 11 区域 | 拖转地球认识七大洲四大洋的相对位置；进入区域后地形/气候/植被/动物全部变化 |
| **地理知识** | 知识卡片 | 每区域 3 张卡片（共 33 张），讲地貌成因与标志性景观（马里亚纳海沟、东非大裂谷、亚马逊雨林、大堡礁……），配程序化剪影插图 |
| **生物知识** | 生物图鉴（F2） | 数据驱动的 175 种动植物档案（中文名/英文名/学名/科普短句），按界→类筛选、按名字搜索；地图介绍页「看看这里的生物」一键跳到对应地区筛选 |
| **知识问答** | 图鉴问答页签 | 题库来自 `data/bestiary/quiz.json`（极地/海洋/大洲/植物四主题，附讲解），答对计入进度连对奖励 |
| **生物** | 生长阶段 | 亲眼看到「蛙卵→蝌蚪→青蛙」「卵→毛毛虫→茧→蝴蝶」的变态发育 |
| **环保** | 保护动物名录 | 大熊猫/金丝猴/朱鹮/白头海雕/北极熊/袋鼠不可伤害，绿色名牌 + 解释提示 |
| **材料与工艺** | 工具分级 + 冶炼 | 从徒手到铁器，理解「工具决定能加工什么材料」；矿石有等级门槛，铜→青铜→铁的技术阶梯 |
| **计量与规划** | 合成配方 | 配方显示所需数量，材料不足描红框——数数与凑单 |
| **知识检验** | 知识问答 | 25 题覆盖地理、生物、工具、机制，答案均可在游戏内找到线索 |

**知识卡片的出题复用**：问答题目直接取材于 `REGION_CARDS`，所以「读过卡片 → 答得出题」这条链路是闭合的。

### 11.3 界面一览

| 界面 | 键 | 行为 |
|------|----|------|
| 合成台 | E | 左栏成品栏（6 格一行单选）+ 右栏合成路径图（顶端成品、下层材料，不足描红）；悬停出 3D 预览；「开始合成」在窗口右下角 |
| 背包 | B | 常用区 **27 格（9 列 × 3 行）** + 待售区 9 格 + 快捷栏管理行；支持拖拽、±搬运数量、一键售卖 |
| 储物箱 | 右键箱子 | 上箱体 36 格 + 下背包 36 格；点格整叠双向转移 |
| 交易 | T | 13 条交易（食物/材料/工具/图腾），需绿宝石 |
| 任务与成就 | J | 双页签 + 进度条 + 领奖 + 内嵌知识问答 |
| 说明书 | F1 | 8 页签分页说明，底部整窗宽状态栏随页显示 Tips |
| 地图选择器 | M | 3 页：3D 地球（拖转 + 射线拾取）→ 区域介绍（含 3 张知识卡片）→ 加载页（逐条揭示后解锁「开始探索」） |

**面板行为的两类规则**：

- **模态窗口**（地图选择器、任务面板）：冻结玩家，必须关闭才能继续。
- **阅读/操作窗口**（说明书、储物箱、合成台、背包、交易）：不冻结玩家，只接管鼠标。

HUD 常驻元素：右上角圆形小地图（黄铜指南针框、北为红）与小地图下方时钟（「第 N 天 白天 HH:MM」）、左上角姓名 + 5 颗生命爱心（每颗 4 点，余量 2 点画半心）、左下角模式标签与半透明系统日志区（播报「获得 xxx」「需要青铜镐」等）、中央准星与蓄力/破坏进度条、顶部居中当前地图名、顶部 Toast 提示。

## 12. 生存机制细节

- **生命**：20 点 = 5 颗心。受跌落、怪物攻击、饥饿伤害。
- **饥饿**：0~20，站着不动 **0.02/秒**（满值可撑 1000 秒 ≈ 1.7 个白天），冲刺额外 **0.06/秒**；归零后每 **5 秒**扣 1 点血。吃到 20% 以下时 HUD 提示「该吃东西了」。
- **掉血播报**：每次扣血都带来源广播（饥饿 / 摔落 / 生物名 / 箭矢 / 卡住），HUD 以 Toast 显示「💔 被僵尸打中了 −2（剩 8）」——看不见原因的掉血只会被当成 bug。
- **受击无敌帧**：被生物命中后 0.5 秒内的再次命中全部忽略，避免一群怪在同一瞬间把血条清零。
- **跌落伤害**：落差 3 格内免伤，超过部分按系数扣血。
- **昼夜**：白天 10 分钟；入夜后前 40% 夜程完成变黑（环境光压至 0.08、天幕深蓝近黑），整夜保持；方向光与环境光/天幕同步调制。
- **防卡死保护**：脚部与头部同时处于实心方块内且持续超过 3 物理帧 → 判定嵌入地形，瞬间死亡并在安全点重生（向上扫描「两格空气 + 实心底」的落点）。创造模式同样生效（否则无敌会卡到死循环），且不消耗不死图腾。
- **不死图腾**：受致命伤时自动消耗 1 个，回复半血。
