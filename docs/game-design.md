## 1. 定位

**Block Planet** 是一款面向儿童的像素体素沙盒游戏。玩家以第一人称（可切换到第三人称）在一个由方块构成的世界里采集、建造、生存、探索与飞行，并可以通过 3D 地球在不同地理区域之间旅行。

- **一句话**：会带孩子环游世界的地理沙盒。
- **角色**：玩家形象为方块小人，默认姓名「小方块」。
- **引擎/平台**：Godot 4.6（Mobile 渲染器），GDScript 2.0；目标设备为中低端 Android 手机/平板，桌面端同样可玩。
- **形态**：单机离线。无联网、无联机、无排行榜、无云存档；不申请网络权限，仅申请本地存储权限。

### 1.1 目标用户

| 维度 | 设定 |
|------|------|
| 年龄段 | 约 6~12 岁，以及陪同的家长 |
| 识字水平 | 能读简单句；所有交互必须有图标/颜色冗余提示 |
| 操作能力 | 触屏为主，鼠标键盘为辅；不接受需要精确时序的操作 |

### 1.2 设计原则（红线）

1. **无恐怖、无血腥**。怪物一律「可爱化、小型化」（小僵尸/小骷髅/小蜘蛛）。死亡是被弹回出生点，不出现任何伤口、血液、骷髅尸体特写。
2. **不惩罚好奇心**。破坏不可逆的惩罚降到最低：掉落物直接进背包；保护动物不可伤害；矿石等级不足时给出**明确提示**而非无声失败。
3. **知识必须可验证**。所有探索内容（地理卡片、问答）的答案都能在游戏内的说明书或知识卡片中找到线索，不依赖外部资料。
4. **鼓励而非逼迫**。任务系统全部是正向目标，没有倒计时压力；没有失败结算界面。
5. **一个界面只教一件事**。每个面板（合成台/储物箱/说明书/任务）只承载一类操作。

## 2. 游戏模式

| 模式 | 状态 | 行为差异 |
|------|------|----------|
| **生存模式** | ✅ 已实现，默认模式 | 有生命/饥饿；方块需采集；有工具耐久；夜晚生成敌对生物；不能飞行 |
| **创造模式** | ✅ 已实现 | 无限方块、无敌、可飞行（双击空格）、饥饿不消耗；G 键切换 |
| **探索模式** | ✅ 已实现（M7.1 模式本体 + M8.7 飞行玩法 + D-042 航海玩法） | 生存机制照常（生命/饥饿/掉落/耐久），但不生成敌对生物、可飞行（双击空格）、G 键禁切创造；开局赠送一架轻型飞机（每次启动进程一次），地图选择器地球页底部提供「生存 / 创造 / 探索」三选一，点选即时生效；地图页的飞行小飞机标记与 🏁 赛道竞速入口仅在探索模式显示（D-041 / D-044；四大洋球面另有小鱼标记表示可钓鱼）；进入四大洋（带降落场海岛）额外发放一艘木筏并建港，驾船出海后主界面切换为航海模式，出海越远可钓的鱼种越珍稀（D-042） |

模式切换：`G` 键 / 触屏「模式」按钮。模式通过 `GameState.set_mode()` 广播 `mode_changed` 信号，HUD、玩家控制器、生成器均订阅该信号，不存在各处自行读枚举的分叉。

## 3. 核心循环

```
   采集 ──▶ 合成 ──▶ 建造 ──▶ 生存 ──▶ 探索新区域
    ▲                                        │
    └──────────── 新材料 / 新工具 ◀───────────┘
```

1. **采集**：破坏方块（原木、石头、矿石、作物）获得资源；狩猎与垂钓获得食物与材料。
2. **合成**：合成台做工具/方块/食物；冶炼炉把矿石炼成锭。
3. **建造**：自由搭建房屋、金字塔、桥梁；储物箱收纳物资。
4. **生存**：管理生命与饥饿，夜晚躲避或反击敌对生物，饿了吃东西。
5. **探索**：按 M 打开 3D 地球，选择一个区域进入——那里的地形、植被、动物、天空色调全部不同。

**探索目标嵌在循环里**：每进入一个新区域，会通过加载页与知识卡片介绍该区域的地理特征；任务系统把「去村庄交易」「踏足新大陆」「炉火初燃」串成新手引导链，边玩边学。

**飞行支线循环（探索模式主题玩法）**：造飞机（V 工坊台拼零件）→ 试飞 → 飞行任务（K）→ 绿宝石奖励 → 解锁进阶零件 → 再改造。这条沙盒循环与上面的采集主线相互供给——飞行任务赚的绿宝石用来买涡轮发动机与长航程机翼，改造出的飞机又能飞得更远、看更多的区域（详见第 9 章）。

## 4. 世界与区域

### 4.1 世界结构

- 区块尺寸 **16 × 64 × 16**，海平面固定 `y = 22`。
- 以玩家为中心流式加载/卸载（`LOAD_RADIUS = 2`），每帧加载 2 个区块，按到玩家的曼哈顿距离升序（脚下与前进方向优先）。
- 玩家修改过的方块记入 `_modified_data`，区块卸载后重载仍然保留——这是建造不丢的根基。
- 地形由 `FastNoiseLite` 生成：平原、丘陵、山脉、水面、树木、石层与矿脉。

### 4.2 11 个可进入区域（七大洲 + 四大洋）

| 区域 | 一句话 |
|------|--------|
| 太平洋 | 世界最大的海洋 |
| 大西洋 | 呈 S 形的第二大洋 |
| 印度洋 | 季风最典型的大洋 |
| 北冰洋 | 最小最浅的大洋，终年结冰 |
| 亚洲 | 面积最大的洲（默认区域，含雪线高峰与大熊猫） |
| 欧洲 | 海岸线最曲折的洲，林木最密 |
| 非洲 | 沙漠与热带草原 |
| 北美洲 | 山脉纵贯的大陆 |
| 南美洲 | 安第斯与亚马孙，雨林密度全图最高 |
| 大洋洲 | 荒漠与草原之洲 |
| 南极洲 | 冰盖与极昼极夜 |

**每个区域独立配置**（`RegionAtlas.REGIONS`）：

| 参数 | 作用 |
|------|------|
| `seed` | 本区独立随机种子，矿脉/树木/水体均可复现 |
| `base_height` / `amplitude` | 地形基准高度与起伏幅度 |
| `surface` / `surface_low` / `low_line` | 地表材质分界（如非洲：低地沙丘、高地草原；两极全雪） |
| `sub` / `sub_low` | 地表下三格的材质 |
| `tree_density` | 每列生成树的概率 |
| `sky` | 天空色调（乘算到天幕与环境光） |
| `passive` / `hostile` | 白天动物与夜晚敌对的加权生成表（北冰洋为空表，即「没有动物」） |

### 4.3 区域切换的实现

地图选择器 → 选定区域 → `GameState.set_region()` → `Main` 执行 `reload_current_scene()`。

- 区块、村庄、生物、HUD **全部随场景重建**，避免手工清理世界状态（这是本项目最重要的一条架构选择，见 `decisions.md` D-007）。
- 背包通过 `GameState.carried_inventory` 跨重载携带，切图不丢东西。

## 5. 方块与物品体系

### 5.1 方块（`BlockTypes.Block`，26 种）

- **自然**：草、泥土、石头、沙子、原木、树叶、水、雪
- **矿产**：铜矿石、锡矿石、铁矿石、金矿石
- **加工**：圆石、玻璃、羊毛、木板系（由原木合成）
- **功能**：储物箱、冶炼炉、酿灶台、耕地、小麦作物
- **水生植物**：水草、藻类、浮萍、荷叶、莲花

每种方块登记：显示名、短名、是否固体、是否透明、纹理瓦片、硬度、**有效工具类别**、**最低工具等级**。

### 5.2 物品（`ItemTypes`）

- **工具 26 件**：木/石/青铜/铁 各配 镐·斧·锹·镰（16 件）+ 银/金 镐·斧·锹（6 件）+ 木/铁鱼竿（2 件）+ 木/铁弓（2 件）。
- **飞行器 1 件**：轻型飞机（合成：铁锭 4 + 木头 6 + 线 2；创造模式快捷栏有货）——手持右键在身前平地放下，走近按 F 登机（见第 9 章）。
- **材料**：铜/锡/青铜/铁/银/金/合金锭、水晶、碳棒、兽皮、羽毛、獠牙、箭、骨头、线、绿宝石、不死图腾。
- **食物**：生牛排（+8）、生鸡肉（+5）、生猪排（+6）、面包（+7）、生鱼、生虾、蟹肉。
- **堆叠上限**：100。工具不堆叠，按耐久独立记录。

## 6. 工具分级系统（M8.1）

### 6.1 四个等级

| 等级 | 材质 | 挖掘倍率 | 典型来源 |
|------|------|----------|----------|
| 1 | 木头 | 2.0 | 手搓 |
| 2 | 石头 | 4.0 | 手搓 |
| 3 | 青铜 | 6.5 | 冶炼（铜锭 + 锡锭） |
| 4 | 铁 | 9.0 | 冶炼（铁矿石） |
| — | 银 / 金 | 11.0 / 13.0 | 交易 / 冶炼（进阶变体，不占等级位） |

### 6.2 工具与场景的对应

- **镐** → 石头、矿石、圆石、冶炼炉
- **斧** → 原木、木头类
- **锹** → 泥土、沙子
- **镰** → 小麦、水草、藻类、浮萍（收割有额外产出加成）
- **鱼竿** → 捕捞鱼/虾/蟹
- **弓** → 远程狩猎与自卫

### 6.3 矿石等级门槛（`MIN_TIER`）

| 矿石 | 最低镐等级 | 提示语 |
|------|-----------|--------|
| 铜矿石 | 任意（含徒手） | — |
| 锡矿石 | 1 木镐 | 「需要石镐才能采到锡矿」 |
| 铁矿石 | 2 石镐 | 「需要青铜镐才能采到铁矿」 |
| 金矿石 | 3 青铜镐 | 「需要铁镐才能采到金矿」 |

等级不足时**方块照常被破坏，但不掉落**，并在左下角系统日志区播报明确提示——避免孩子「默默挖了半天什么都没有」的挫败。

**地层分布**（概率由确定性哈希决定，坐标级可复现）：

| 矿石 | 出现概率 | 深度限制 |
|------|---------|----------|
| 铜 | 2.5% | 全石层 |
| 锡 | 1.0% | 海平面 +2 以下 |
| 铁 | 1.0% | 海平面 −6 以下 |
| 金 | 0.4% | 海平面 −12 以下 |

**材料获取路径是挖矿与交易的混合**：铁/金靠挖矿，银/水晶/碳棒靠村民交易与闯关奖励。

## 7. 生物与生态

### 7.1 生物名录（22 种）

- **敌对（3）**：小僵尸、小骷髅（远程射箭）、小蜘蛛
- **凶狠中立（2）**：狼（夜晚与敌对同池生成）、掠夺者（白天驻守掠夺塔）
- **家畜（4）**：牛、羊、鸡、猪
- **水生物（5）**：鱼、虾、蟹、蜻蜓、青蛙
- **村民（1）**：大鼻子村民（永续被动，可交易）
- **保护动物（6）**：大熊猫、金丝猴、朱鹮、白头海雕、北极熊、袋鼠
- **新增（1）**：蝴蝶

### 7.2 生成规则

- **敌对生物**：夜晚在玩家周围生成（上限 8 只），出生点向上扫描真实落点，避开树干与建筑；白天全部清空。
- **被动动物**：白天在草地上生成（上限 6 只），白天不清空；撞墙换向，受击逃跑（反击名录中的先反击）。
- **水生物**：独立生成轨道（不与陆地上限互挤），按栖息地分派——大河中鱼潜游、蟹贴底爬行、虾游弋，池塘中蜻蜓悬停浮动、青蛙岸边间歇起跳。
- **区域加权**：每个区域有自己的白天/夜晚生成表。北冰洋白天为空表（只有风雪与脚印），亚洲额外有大熊猫/金丝猴/朱鹮，北美有白头海雕，大洋洲有袋鼠，北极圈有北极熊。
- **村庄 NPC** 由 `VillageBuilder` 直接挂在主场景，绕开生成器的昼夜清空与补货逻辑。

### 7.3 生长系统（M8.2）

每种动物有一条**成长阶段链**（`MOB_STAGES`），由**游戏天数**驱动推进，每过一个游戏日推进一个阶段：

| 生物 | 阶段链 |
|------|--------|
| 鸡 | 鸡蛋 → 小鸡 → 鸡 |
| 青蛙 | 蛙卵 → 蝌蚪 → 青蛙 |
| 蝴蝶 | 蝶卵 → 毛毛虫 → 茧 → 蝴蝶 |
| 鱼 | 鱼苗 → 小鱼 → 鱼 |
| 牛 / 羊 / 猪 | 幼崽 → 成体（两段，胎生） |

- **视觉**：按阶段整体缩放 + 卵/蝌蚪/毛毛虫/茧有专用小模型。
- **属性**：以成体为基准，按阶段倍率换算（生命、速度、掉落量）。基础值与当前值双记录，保证阶段切换反复调用无损。
- **掉落**：幼体掉落更少（如小鸡只掉羽毛），成体才产出主产物。
- **生成器默认以成体出现**，只有小概率抽中幼体，避免「出门全是宝宝」影响体验。
- **持久化**：生长阶段随存档保存（依赖 M7 SaveManager，规划中）。

### 7.4 保护动物（M8.2）

**名录**：大熊猫、金丝猴、朱鹮、白头海雕、北极熊、袋鼠，以及村民、蜻蜓、蝴蝶。

- 头顶名牌显示为**绿色**，与普通生物的白色、反击状态的红色区分。
- **无法被伤害**：攻击被拦截，只显示解释性提示（如「大熊猫是国家一级保护动物，请不要伤害它」）。
- 弓射出的箭命中保护动物同样免伤——保护是**跨武器一致**的。
- 设计意图：把「不能伤害珍稀动物」做成游戏机制而不是口头说教。

### 7.5 反击机制（M8.3）

北极熊与蟹受击后会进入**反击状态**（名牌变红），主动追击攻击者。这是给玩家的唯一「主动招惹有代价」的反馈，其余被动动物只会逃跑。

## 8. 狩猎与垂钓（M8.3 / M8.4）

### 8.1 狩猎规则引擎

`HuntRules` 用一张规则表回答「用这个工具打这只生物，会发生什么」：

| 猎物 | 所需工具 | 最低等级 | 基础伤害 |
|------|---------|---------|---------|
| 牛 / 羊 / 猪 / 鸡 / 小僵尸 / 小骷髅 / 小蜘蛛 | 斧 | 1 | 4 |
| 狼 / 掠夺者 | 斧 | 2 | 4 |
| 鱼 / 虾 / 蟹 / 蛙 | 鱼竿 | 1 | 5 / 4 |

- **工具不对**：伤害折半，并给出提示（教孩子「砍树用斧头，收麦用镰刀」）。
- **徒手**：基础伤害 1，明显低于正确工具，鼓励做工具而不是硬敲。
- **逐级掉落**：掉落按**物种 + 生长阶段**决定，成体产出主产物（生牛排/羊毛/生鸡肉/生猪排/兽皮/獠牙），幼体只有边角料。
- **工具耐久**：只有真正用到对应工具时才磨损。

### 8.2 弓箭（蓄力射击）

- 右键**按住蓄力**（0.15s 起效，1.2s 蓄满），松手射出；蓄力条显示在屏幕准星下方。
- 伤害随蓄力比例在 2~6 之间线性变化。
- 每射一箭消耗 1 支箭（合成一次得 4 支）。
- 与骷髅的箭共用 `ArrowProjectile` 实体，但分敌对/玩家两个模式，玩家箭命中保护动物与幼体**免伤**。

### 8.3 垂钓（抛竿 → 等待 → 咬钩 → 收竿）

- 手持鱼竿右键抛竿，浮标（红白相间）落到水面，钓线从浮标拉向相机。
- 等待 3~8 秒后浮标下沉（咬钩），有 1.6 秒**收竿窗口**。
- 窗口内收竿 → 按权重抽取战利品（几乎都是鱼虾，偶尔混进水草）；错过窗口 → 空手。
- 随时可以提前收竿，不会卡状态（安全兜底）。
- 钓到的鱼同时服务两条线：食物，以及「渔夫」成就。

## 9. 飞行玩法

> 对应技术决策 `decisions.md` D-031（飞行器 + 简化气动）与 D-032（零件拼装 + 聚合气动 MVP）。
> 飞行是探索模式的第一玩法；生存 / 创造模式同样可以合成并使用飞机。

### 9.1 飞行器：放一架飞机，飞起来

- **获得**：合成（铁锭 4 + 木头 6 + 线 2），或探索模式开局赠送；手持右键在身前平地放下。放置不做体积校验——贴山放机会被地形顶开。
- **驾驶**：走近按 **F 登机**、按 **X 下机**（停稳后双击 X 收回）；驾驶中 **F = 启动 / 熄火**发动机（熄火后无推力，但舵面仍可操纵，飞机可滑翔）。驾驶期间玩家物理冻结、位置每帧贴到座舱位。登机默认熄火——第一次按 F 只是坐进座舱，再按 F 才点火。
- **飞行视角**（C/V/M/R，见 9.6）：C 切第一 / 第三人称、V 或按住右键自由观察（松手自动回正）、M 战术地图、R 后视；滚轮调追尾距离 / 地图高度。
- **简化真实气动**（240 kg 短距起降机，「可读的简化」而非工程模型）：失速 13.1 m/s、结构限速 VNE 55 m/s、满油门平飞约 50 m/s、起飞滑跑约 18 m、L/Dmax ≈ 8。升力/阻力/推力/重力 + 攻角失速曲线 + 空气密度随高度衰减 + 操纵权限随动压下降；压坡度自然转弯；拉杆必然掉速（诱导阻力随升力系数平方增长）。
- **机体尺度**：1 格 = 0.5 m；机模放大后机身约 10.2 m、翼展 24 m（比村庄民居大一圈）；碰撞盒只包机身——翼展不参与碰撞，不会一路刮蹭树冠屋檐。
- **解体**：单帧速度损失 ≥ 7 m/s（撞墙、硬着陆）即解体——抛出乘员并扣血，残骸 4 秒后消散。
- **HUD 飞行仪表**：登机后按视角显示飞行仪表（见 9.8）；「离地」用向下射线实测，越山头随地形起伏。
- **飞行成就**：展翅高飞 / 冲上云霄 / 空中漫游（见 11.2）。

### 9.2 零件拼装与蓝图（V 工坊台）

飞机 = 多个零件拼装，每个零件贡献 质量/升力/阻力/推力/耐久；整机特性由聚合推导——**装什么决定什么**。

- **七种默认零件**：机身 / 机翼 / 尾翼 / 发动机 / 螺旋桨 / 起落架 / 油箱。默认套件 Σ240 kg、翼面积 14 m²、推力 1650 N——与「整机烘焙常数」时代的标定逐项一致，重构后飞行动作不变。
- **两个绿宝石进阶零件**：涡轮发动机（30 绿宝石，推力 1750 > 1650——飞得快，但也更接近结构限速）、长航程机翼（20 绿宝石，升力面 18 > 12，失速更慢）。整机 VNE 取所有零件结构限速的下限。
- **V 键工坊台**（模态冻结；上下文分流——**非飞行态**按 V 打开，飞行中 V 是自由观察，要建造请先按 X 下机）：3D 预览 + 轨道相机；放置 / 删除 / 旋转 / X 轴对称镜像；重心（红）/ 升力中心（蓝）/ 推力线实时可视化；连通性校验（必含机身、从机身邻接可达全部零件）；蓝图存读 `user://blueprint.json`；按 X 直接把当前蓝图试飞上天。
- **蓝图机外观** = 零件体素块（纯视觉、无碰撞）；暂不转螺旋桨、不播舵面动画、涂装不生效（MVP 边界）。
- **解锁状态**落盘 `user://unlocks.json`——任务赚的绿宝石买的零件跨会话保留。

### 9.3 飞行任务（K）

K 键唤出模态任务面板，三任务锚定机场 / 降落场布设：

| 任务 | 目标 | 奖励 |
|------|------|------|
| 起飞 | 离地 30 m 且空速 ≥ 40 km/h | 绿宝石 ×5 |
| 绕点 | 按顺序经过全部航点（绕场矩形） | 绿宝石 ×5 |
| 降落 | 触地垂直速度 ≤ 3 m/s，停稳（≤ 25 km/h）在跑道面上 | 绿宝石 ×5 |

- 任务**可重复进行**（反复挑战刷分无惩罚），但奖励**每任务每进程仅领一次**：同一任务再次成功仍判完成、仍计分，绿宝石不再重复入包，任务卡标注「奖励：已领取」。重启游戏后可重新赚取。
- 面板外也能玩：飞行中下机 = 主动放弃当前任务，随时可以再开。
- 奖励绿宝石直接入库存，用于工坊台解锁进阶零件——「任务 → 奖励 → 改造」闭合到现有货币体系，不建平行经济。

### 9.4 飞行设置与涂装（O）

- **难度三档**（休闲 / 标准 / 硬核）× **辅助稳定三档**（关闭 / 半开 / 全开）。辅助稳定只在**松杆且未失速**时接管：把坡度配平回水平、阻尼偏航；玩家一压杆立刻完全让位，绝不干预俯仰机动。
- **4 套涂装**：经典红白 / 深海蓝 / 丛林绿 / 落日橙，随时切换、随设置落盘。
- 所有改动即时生效并保存到 `user://settings.json`（缺失/损坏退回默认「标准 + 半开」）。

### 9.5 机场与降落场

- **6 个大陆区域**建有带跑道的小机场：圆石跑道 + 沙色跑道头 + 四色自发光导航灯（南绿门槛 / 北红远端 / 黄虚线中线 / 白边缘线，进近方向由南向北）+ 南端开放式机库。出生点就在跑道南段——开局站在跑道上，落地即可起飞。
- **跑道尺寸按翼展定**：52 格宽（26 m）× 112 格长（56 m，D-040 应用户要求由 56 格加倍）。翼展 48 格（24 m），两侧各留 2 格余量，因此整机（含翼尖）都落在铺装面内；机库另用独立的 12 格宽（6 m），不随跑道加宽。机场中心按「跑道半宽 + 整平余量」让开村庄：大陆区 x=114（村庄结构最右 x=79）。
- **探索模式开局**：跑道上停着一架可登机的飞机（停在出生点正北 19 格处），且**开局镜头正对飞机**——进入游戏第一眼就能看见它，不必转身。走到跟前按 F 登机。
- **4 大洋与南极洲**是简易降落场（**简易起降条带**：10 格宽 × 32 格长，无机库）。它比机身碰撞盒（13.2 格 × 31.2 格）还窄，只保证「停稳即用」，不承诺整机落在铺装面内——这是有意的区别：小岛 / 冰面放不下 26 m 宽的场地。
- 地图地球上，机场区域带红色标记、降落场带琥珀色标记。
- 机场 / 降落场皆无的区域，任务航路与降落区自动锚定出生点。

### 9.6 飞行视角与回放（C / V / M / R / P）

六模式相机 rig（场景级独立节点，按机体位姿每帧算目标、指数阻尼逼近——**平滑过渡、永不瞬移**）：

| 模式 | 键 | 说明 |
|------|----|------|
| 座舱第一人称 | C | 眼位在座舱罩内（机头上仰基础上再抬一点，看得见天地线） |
| 追尾第三人称 | C | 默认 **13 m / FOV 82°**（比旧弹簧臂 9 m / 70° 更远更宽；D-035 由 75° 加宽）；抑制滚转、地平线稳定；被地形挡住自动拉近 |
| 自由观察 | V / 按住右键 | 鼠标（或右摇杆）环顾；**松手自动回正**（τ≈0.4 s，防晕）；贴地时只保留偏航防沉入地下 |
| 战术地图 | M | 2D 俯视面板：地形网格、机场 / 降落场条带、任务航点与降落区、虚线航线、罗盘 + 比例尺、滚轮 / 双指缩放 |
| 后视 | R | 后视镜式：相机在机头前方回头拍（看机尾方向） |
| 回放 | P / 任务成功自动 | 电影运镜 + 机体重演 + 幽灵轨迹（见下） |

- **儿童友好三件套**（O 面板可调、随设置落盘）：镜头抖动（发动机运转时 < 8 cm 低频噪声，可关）、松手自动回正（可关）、默认追尾更远视野更宽。
- **飞行操作新增**：空格 = 上升（离地后；在地面仍是机轮刹车）、Shift = 加速、Ctrl = 下降；F = 启动 / 熄火。
- **回放**：任务成功（着陆判定）后 1.2 s 自动开演，也可随时按 P 手动开；分镜 环绕→座舱→追尾→俯视→翼侧（每镜约 3 s、切换前 0.6 s 混合不硬切），叠加一条随时间渐亮的幽灵轨迹条带；Esc / P 跳过。**回放对机体是「时间未流逝」**——结束时位姿与速度态一并还原，滑跑中触发回放、演完照样继续滑行至停。
- **触屏**：飞行触控层追加「视角 / 发动机」两个按钮（与 C / F 等价）。
- **视场**：飞行各视角统一 **FOV 82°**（战术地图仍 70°，图上比例要稳定）。飞行需要
  的是周边感知——地平线、侧向地标、进近跑道与目标点都要进画面，徒步时够用的 75°
  在座舱里被仪表盘与舱框一挡就只剩一条缝（D-035）。
- **飞行流式加载**：登机后地形加载窗口从徒步的 5×5 方形（40 m 见方）切换为**沿机头
  方向的偏置矩形**——前方 5 个区块（48 m）、侧向 2 个、后方 1 个，并把每帧限量改为
  时间预算（8 ms/帧，单块更慢时也不会吃掉整帧）。队列按「近处优先、同距离前方优先」
  推进——**脚下区块必须最先落地**（否则飞机悬空）。50 m/s 巡航时前方 24 m 窗口内不再
  出现地形缺口（实测平均缺 0.00 块），下机后窗口回落（D-035）。

### 9.8 飞行仪表与 HUD（D-034）

数据层统一：登机后 `Aircraft.snapshot()` 的原始读数每帧经 `FlightInstruments`
（纯逻辑 `RefCounted`，`scripts/flight/flight_instruments.gd`）加工成 **12 项仪表**
+ 告警，座舱 3D 仪表盘、屏幕 HUD、无头探针共用同一份数字。12 项：空速表 /
姿态仪 / 高度表 / 转弯协调仪 / 航向指示器 / 垂直速度表 / HSI / CDI / 雷达高度表 /
发动机转速 / 燃油表 / 襟翼·起落架指示灯。

- **默认视角 = 座舱（D-049）**：登机即第一人称座舱（`AircraftCamera.reset_to_cockpit()`，
  每次登机复位，覆盖层退出也回座舱），鼠标随即成为操纵杆（左右滚转、上下俯仰；
  滚轮在座舱内是油门微调 ±5%）；C 键与追尾互切，R 后视 / V 环顾 / M 地图 / 中键归位。
- **座舱仪表板（第一人称，D-047 → D-052 战雷化 → D-053 压缩）**：`CockpitInstruments`（`scripts/flight/cockpit_instruments.gd`）
  纯 2D 像素绘制，屏幕最上层叠加在座舱视野之上（不用 3D / ViewportTexture）。黑盘面 + 白色
  硬边刻度、粗像素、参考战雷老式战机仪表。D-052 起是**一块金属仪表板**而不是几块散件：
  **航向带**（600×56 罗盘带：上下金属条、两端渐隐、琥珀指针指机头、带下三位航向数，
  359°→0° 取模连续不跳变）+ **地平仪**（主表 152 圆盘，居中：底层天地按俯仰垂直偏移、
  按横滚整体旋转，±60° 截断不无限滚动；天地用「圆 ∩ 地平线半平面」裁进表盘；上层
  固定琥珀飞机标记不随姿态动，俯仰阶梯只画盘缘两侧、横滚刻度沿内缘）+ **高度计**
  （140 圆盘，白色数字 `ALT 4500m`，过低变红并 600ms 闪烁）+ **空速**（同款圆盘，
  `113 km/h`）+ 盘排两侧 **THR / FUEL 竖条** + 竖条与侧盘之间的**封板**（未装仪表的
  方孔盖板，凹陷钢板 + 四颗螺钉）。三个圆盘 + 两条竖条 + 封板 + 航向带全部嵌在
  金属板上（拉丝横纹、螺钉、每盘凹陷阴影环）。比例自适应：基准视口 1280×720 ×
  `ui_scale = min(w/1280, h/720)`，主表恒占屏高 14.1%（`aspect=expand` 的宽高比漂移被压平）。
  尺寸纪律：D-049 放大 16% 后被用户「太大了」打回；D-052 维持 D-051 量级；**D-053 用户
  圈注「红框 2 高度缩小 1/3」，盘排竖向 ×2/3（`GAUGE_K`），仪表板占屏高 32.8% → 25.2%、
  主表 152 → 101**。航向带尺寸与 dash 宽度不动（宽度由带宽决定，用户只要求高度）。
  改版不得再借"战雷化"把尺寸顶回去。
- **HUD 层级（D-052 重构 / D-053 收敛）**：座舱视角只留「仪表板 + 准星 + 警告横幅」。
  飞行卡片移到左上且**只保留失速行与起飞教练区**（SPD/ALT/航向/油门/燃油已在表上）；
  无失速无教练时整卡隐藏。追尾视角仍是顶部居中全读数卡片。警告横幅位置随视角走
  （座舱 y16 / 追尾 y240），永不与卡片对穿。**D-053 起登机后右上角整列全收**：小地图、
  模式徽章、天数·时钟·天气行都不再显示（用户圈注要求取消；徒步仍全部保留）。
- **飞行指引十字（Flight Director Cross，D-054）**：`FlightDirector`（`scripts/flight/flight_director.gd`）。
  座舱中心从此有**两个十字**，语义不同：白色细十字是**准星**（机头现在指哪，固定不动），
  彩色粗十字是**指引十字**（机头应该指哪，随偏差偏移，限幅 ±120 px）——玩家把准星套进
  指引十字，就等于沿正确航径在飞，这是真实飞行指引仪（FD command bars）的用法。
  引导律「偏差角 × 11 px/度」：水平取 CDI 方位偏差（正 = 目标在右），垂直取 **3° 下滑道
  的高度偏差**（高于道 → 低头追回，符号不能反）。五个模式：**滑跑**（贴地，保持起飞航向）/
  **起飞**（离地爬升，引导 8° 爬升角）/ **进近**（距机场 ≤400 m，3° 下滑道）/ **巡航**
  （>400 m，只引导航向不压高度）/ **关闭**（无导航目标或停机）。颜色三档：绿（两轴都
  <1.5°，加四角捕获括号并显示「对准」）/ 琥珀（<12°）/ 红；超量程时在十字外侧补一枚
  同向箭头，标签优先给**动作词**（左转/右转/掉头/抬头/低头）而不是模式名。「起飞」判据
  必须靠升降率 + 离地高度，只按距离会在离地那一刻误判成进近并提示低头。仅第一人称显示，
  目标与 HSI/CDI、世界 3D 标注同源。
- **座舱内视 + 2D 像素座舱框（D-050 / D-051 座舱感）**：第一人称（含以座舱为底层的环顾）下
  隐藏 3D 外部机模——座舱眼位在机身盒内部，机翼正压视平线，不隐藏的话「第一
  人称」看到的是自己的机翼横贯全屏（用户实测反馈）；切追尾 / 下机即恢复（飞机
  仍停在场上，防「幽灵飞机」）。座舱内装由 `CockpitInstruments._draw()` 的 2D
  像素座舱框提供（D-047 spec 的「驾驶舱像素背景」）：**风挡支柱**（顶檐下左右斜边
  内收，世界从两道斜边之间望去）+ **左右侧 console**（缝线、按键网格带 LED、
  通风栅、警告灯、铆钉）+ **仪表 dash 底板**（四件仪表坐在其上，底沿即屏底＝座舱
  地板）+ **磨损像素细节**（确定性坐标哈希的稀疏亮/暗噪点与风挡划痕，静态帧不随
  姿态闪烁）。D-034 的座舱 3D 仪表盘同规则在座舱视角隐藏（读数由 2D 簇接管），
  追尾 / 地图 / 回放恢复。
- **追尾四角 HUD（第三人称）**：TL 空速·航向 / TR 高度·升降 / BL 油门%·燃油% /
  BR 目标方位·距离；右下角小地图（北朝上，本机三角指航向、导航绿点指目标）。
- **详细模式（H 键）**：左侧 12 仪表全清单 + 始终显示小地图；默认简单模式（儿童优先，
  信息少 = 不晕，可在飞行设置里关掉简单模式）。
- **座舱 3D 仪表盘**（`CockpitPanel`，SubViewport 贴仪表板）：上排 4 圆（空速/姿态/
  高度/航向）+ 下排 3 圆（转弯协调/垂直速度/HSI+CDI）+ 底部 4 数字条（雷达高度/转速/
  燃油/襟翼·起落架）；低头可见会转动的指针；蓝图试飞机无座舱罩，按契约隐藏。
- **世界标注**（`FlightMarkers`）：目标金色双环 + 悬浮名称/距离；跑道引导 = 地面箭头
  列 + 3° 下滑道双轨（跟着线飞就能落地）；距目标 < 50 m 淡出。
- **警告与蜂鸣**：六类告警（失速/超速/燃油耗尽/过低(两级)/低油），按优先级取最高级
  显示闪烁横幅 + 程序合成蜂鸣（`AlertBeeper`，330–880 Hz、主音量 0.22，零资产依赖；
  预留 `user://voice/<id>.wav` 采样覆盖）；燃油 ≤0.05 L 判耗尽熄火，低油 20% 触发 /
  25% 清除（滞环防抖闪）。
- **襟翼**：Z 单键循环 0→1→2→0；>30 m/s 放襟翼仅提示不硬拦。自动改平：双击左键约
  2 秒增强增益摆平（受「自动改平」设置门控）。
- **主界面联动**：登机后底部快捷栏整条隐藏、左上角状态块（姓名 + 生命爱心 +
  饥饿）**整块隐藏**、右上角圆形小地图（黄铜指南针框）与模式徽章（生存/创造/探索）
  隐藏，只保留右上角的天数·时钟·天气行（`_on_aircraft_ride_changed` 单点控制各
  容器显隐，状态块按容器控制而非逐节点，三个读数一起走，新增状态行自动跟随）。
  状态块隐藏的理由（D-046，用户明说「登机后 1 区不显示」）：飞行中玩家就是飞机
  本身，姓名/血量/饥饿是徒步身份读数，留在屏上只与飞行信息抢注意力——顶部居中
  让给飞行面板（起飞教练已并入其中），左上角整块让出。数值仍由 `player.health_changed`/
  `hunger_changed` 无条件驱动（不经 riding 门控）且只重画/改文本不动显隐，下机
  瞬间显示的就是最新读数而非上机前旧值。**同一处代码的第三次翻转**（D-042 隐藏
  → D-045 应反馈恢复显示 → D-046 用户试玩后改主意重新隐藏），后续以用户明说为准。
  另两项让位：顶部居中世界名驾驶时隐藏（否则紧贴飞行面板标题右侧，读起来像标题
  的一部分）；Toast 从顶部居中挪到**底部居中**（y H-160…H-128，教练横条并入卡片
  后空出的位置），否则三行长登机提示会整行压在卡片读数上。
  `_refresh_hotbar` 只刷子格不动容器、`_refresh_stats` 由 `player.health_changed`/
  `hunger_changed` 无条件驱动（不经 riding 门控）且只重画/改文本不动显隐、
  `_refresh_mode_badge`/`_refresh_time` 同理：模式切换、背包变化（含飞行任务奖励
  入包）、掉血/饥饿变化、昼夜更替都不会把驾驶中的它们放出来。方位信息不会丢：M 键
  战术地图（北上东右）与飞行仪表 HUD 自带的右下角 160×160 小地图（仅追尾视角）
  都在，主小地图只是徒步视角的地形俯瞰。3D 角色模型在 `ride_aircraft` 中即隐藏，
  飞行中玩家就是飞机本身；HUD 状态块也随之隐藏，二者对应（D-046）。
  另见起飞教练（`decisions.md` D-043 / D-046）：原屏幕底部独立横条，D-046 起并入
  飞行面板卡片底部，巡航/失速时整体收起。

## 10. 赛道竞速玩法

> 对应技术决策 `decisions.md` D-036。玩法设计取自 `feature_car_racing.md`，实现按本工程
> 「纯逻辑层可无头测试 + 全代码 UI」的范式落地。

### 10.1 流程与入口

```text
地图选择器（M）→ 左下角 🏁 赛道竞速
→ 赛道选择器：主题筛选 → 选赛道 → 选赛车 → 机器人数量 / 难度 → 开始比赛
→ 切到独立竞速场景 → 3-2-1-GO 倒计时 → 驾驶 → 过检查点 → 冲线
→ 结算界面（名次 / 完赛时间 / 最快圈速 / 是否破纪录）
→ 「再来一次」重载本场；「返回赛道选择」回主场景并直接重开选择器
```

竞速入口不绑定地理区域（赛道自带主题：沙漠/森林/湿地/山地/城市/混合），所以它挂在地图页
左下角、与星球区域无关；钓鱼则相反，只在有钓点的海域出现。竞速入口与地球上的飞行小飞机标记一样
**只在探索模式显示**（D-041：切模式当帧同步，生存/创造下玩家还没有载具，不挂门牌）。
竞速在**独立场景**里跑——
要换掉地形、相机、物理与光照，同场景开面板做不干净。

### 10.2 赛道与地形

- **6 条赛道**：沙丘环线（沙漠 ★★ 1200 m 3 圈）/ 林间小径（森林 ★★★ 1500 m 3 圈）/
  沼泽穿越（湿地 ★★★★ 1800 m 2 圈）/ 盘山公路（山地 ★★★★★ 2200 m 2 圈）/
  城市街道（城市 ★★ 1000 m 4 圈）/ 全地形挑战（混合 ★★★★ 2500 m 3 圈）。
- 赛道是**参数化闭合环线**：`r(θ)=R·(1+amp·sin(lobes·θ+phase)+amp2·sin(lobes2·θ+phase2))`，
  半径 R 由「中心线周长命中 `length_m`」反解，再按 4 m 间距重采样。
- **地形影响抓地、极速与刹车**（数据驱动，HUD 换路段时读数会跟着变）：

| 地形 | 抓地 | 速度 | 刹车 | 直观感受 |
|------|------|------|------|---------|
| 柏油 | 最好 | 最快 | 最好 | 城市与山路主干，最能放心踩油门 |
| 沙石 | 中 | 中 | 中 | 会轻微打滑，尘土飞扬 |
| 森林（落叶） | 中偏下 | 中偏下 | 中 | 林间小径的主体路面 |
| 山坡 | 中 | 中 | 中 | 上坡更费油（对应教学条目） |
| 草地 | 差 | 低 | 差 | 出路面就吃这个，天然惩罚抄近道 |
| 湿地 | 最差 | 最低 | 最差 | 最滑、刹车距离最长，要提前减速 |

- **解锁条件**写在数据里（`default` / `wins:N` / `record:N`），选择器直接把条件写在卡片上
  （「赢 1 场后解锁」）。未知或写错的解锁串一律当作已解锁——儿童向宁多给、不锁死。

### 10.3 赛车

4 台玩家车 + 3 台机器人专用车（数据表 `data/racing/vehicles.json`）：

| 赛车 | 极速 | 抓地 | 特点 |
|------|------|------|------|
| 小三轮 | 24 m/s | 1.00 | 起步稳、转弯灵，第一次上赛道就用它 |
| 越野沙滩车 | 28 m/s | 1.15 | 抓地最稳、油箱最大，沙石与湿地都不容易打滑 |
| 越野摩托 | 34 m/s | 0.90 | 又快又轻，但抓地偏弱，湿地要早点刹车 |
| 赛道方程式 | 40 m/s | 1.05 | 最快，解锁条件「赢 1 场」 |

- 物理是**简化但可读**的模型：动力沿车头加力，阻力系数由「全油门收敛到
  `极速 × 地形速度系数`」反解；转向权限随车速上升（静止打不动方向）；速度矢量按
  `抓地` 的速率朝车头回正——**手刹把回正速率砍到 20%**，「拉手刹甩尾」就是这一条。
- **燃油**：油量表是真实读数，重油门与上坡掉得更快（教学条目「上坡更费油」）。油量按
  「任何非终局赛道都能跑完」标定，**不会半路抛锚**。

### 10.4 机器人对手

- 0~5 台，4 档难度（简单/普通/困难/专家），同场与玩家一起跑。
- 驾驶策略：沿前方路点取**前瞻点**（前瞻距离随车速增长），根据前瞻点与车头的偏差给转向；
  弯道误差大就收油；难度决定速度系数、转向精度、反应时间与**犯错概率**（会在弯里短暂
  踩错方向或收不住油）。名字池与车池来自数据。
- 机器人车油箱无限（它们是陪练，不该因为没油停在半路）。

### 10.5 规则与判定

- **检查点用「门平面穿越」判定**：车在门的横向宽度内、且从门的背面穿到正面才算过门，
  必须**按顺序**过（漏门那一圈不计）。这样高速掠过不会漏判、也不受帧率影响。
- 过完最后一个门再穿过起跑线 = 完成一圈并计时；跑满 `laps` 圈即冲线。
- 排名规则：已完赛者按完赛时间先后 → 未完赛者按圈数 → 过门数 → 距下一门的距离。
- 软性边界：竞技场地台之外越界会被拉回并卸掉大部分速度。

### 10.6 记录、回放与任务

- **记录**落 `user://race_records.json`（与只读的赛道定义分开）：每条赛道的最佳圈速、
  最短完赛、场次、胜场、最好/最近名次与时间戳。选择器内置「竞速记录」页，可一键清空。
- **回放日志**落 `user://race_replay.jsonl`（JSON Lines，只留最近 600 行），每行
  `tick / action / track_id / vehicle_id / position / player`，记录
  `race_start`、`checkpoint`、`lap_complete`、`race_finish` 四类事件，作为将来幽灵车
  重演的原始素材。
- **教学**落 `user://race_teaching.json`，首次开赛 / 首次过检查点 / 首次完圈各弹一次。
- **5 条竞速任务**（接在新手链之后）：首战告捷（完成第一场）、沙漠之王（在沙丘环线夺冠）、
  更快一圈（破一条赛道记录）、湿地不拉手刹（在沼泽穿越全程不用手刹完赛）、三轮车冠军
  （用小三轮夺冠）。

### 10.7 操作与 HUD

驾驶中：`W/S` 油门与刹车（方向键与飞行俯仰键同样可用）、`A/D` 转向（键鼠做了一点平滑，
避免二元输入一跳一跳）、`空格` 手刹、`C` 车灯、`F` 喇叭、`R` 重新开始本场、
`Esc` 返回赛道选择。触摸设备沿用左右分区（左转/右转 + 油门/刹车 + 手刹）的最小布局。

比赛 HUD（左上角一栏 + 右下角一栏）：圈数、排名、速度、当前圈计时、最快圈、燃油条，
以及手刹/车灯提示与滑移读数；倒计时与「出发！」「第 N 圈完成」「冲线！」走横幅。

## 11. 任务与成就系统

三层架构：**Events 信号桥 → ProgressManager（Autoload，计数器 + 状态机）→ HUD 任务面板**（J 键）。

### 11.1 结构

- **计数器**：`mined_<block_id>` / `crafted_<item_id>` / `killed_<mob_type>` / `mob_killed` / `placed_any` / `traded` / `regions_<id>` / `grown_*` 等。
- **状态机**：`LOCKED → ACTIVE → DONE → CLAIMED`。达成后需手动点「领取奖励」，强化正反馈。
- **目标类型**：`count`（计数达标）/ `regions`（踏足区域数）/ `distinct_mined`（挖掘过的方块种类）/ `quests_done`（已领任务数）。
- **持久化**：`user://progress.json`，每次计数变化即落盘，跨区域重载存活。

### 11.2 内容规模

| 类别 | 内容 |
|------|------|
| 新手任务链 | **8 环**，按 `prerequisite` 顺序解锁：动手采集 → 小小建筑师 → 初次合成 → 工具匠 → 以物易物 → 打开世界地图 → 踏足新大陆 → 炉火初燃 |
| 竞速任务链 | **5 环**，接在新手链之后：首战告捷 → 沙漠之王 / 更快一圈 / 湿地不拉手刹 / 三轮车冠军 |
| 成就 | **28 枚**，五类分组：知识问答 / 生存技能 / 地图探索 / 游戏闯关 / 新手毕业 |
| 知识问答 | **25 题**，答对 3 题发面包 ×2 |

**新手链的设计意图**：8 环正好把「挖掘 → 建造 → 合成 → 工具 → 交易 → 地图 → 换区域 → 冶炼」这条完整主线走一遍，孩子在拿到「新手毕业」成就时已经掌握了全部基础操作。

**成就举例**：石器时代、点石成金、小小猎手、建筑师、环球冒险家（踏足全部 11 区域）、钢铁时代（合成铁镐）、收割好手（镰刀）、小小弓箭手、垂钓入门、牧场主、渔夫、勇者无畏、小小观察员（看动物长大 3 次）、孵化见证者（看鸡蛋孵出小鸡）、池塘里的秘密（蝌蚪变青蛙）、动物守护者（了解 3 种保护动物且未伤害）；飞行三枚——展翅高飞（第一次驾驶飞机离地）、冲上云霄（爬到离地 60 m 以上）、空中漫游（累计在空中飞行 1000 m）。

**在竞速场景里**（独立场景，见 10.7）：`W/S` 或 ↑/↓ = 油门 / 刹车、`A/D` 或 ←/→ = 转向、
空格 = 手刹、`C` = 车灯、`F` = 喇叭、`R` = 重开本场、`Esc` = 返回赛道选择。上车前在
**赛道选择器**里选好赛道 / 赛车 / 机器人数量与难度（`Esc` 关闭）。

**驾驶飞机时**（详见 9.7 操作速查）：鼠标 = 操纵杆（俯仰/滚转，方向键为键盘替代）、W/S = 油门增减、A/D = 方向舵（地面即前轮转向）、空格 = 刹车 / 上升、Shift = 加速、Ctrl = 下降、F = 发动机、X = 下机、C = 视角、V / 按住右键 = 自由观察、M = 战术地图、R = 后视、P = 回放、Z = 襟翼循环、H = HUD 简单/详细切换；双击左键 = 自动改平。

> 输入统一走 InputMap 动作（运行时注册，幂等），因此键位集中在一处即可改，且玩家控制器与 HUD 都不出现物理键位硬编码。

**面板行为的两类规则**：

- **模态窗口**（地图选择器、任务面板、工坊台建造、飞行任务、飞行设置、赛道选择器）：冻结玩家，必须关闭才能继续。
- **阅读/操作窗口**（说明书、储物箱、合成台、背包、交易）：不冻结玩家，只接管鼠标。

HUD 常驻元素：右上角圆形小地图（黄铜指南针框、北为红）与小地图下方时钟（「第 N 天 白天 HH:MM」）、左上角姓名 + 5 颗生命爱心（每颗 4 点，余量 2 点画半心）、左下角模式标签与半透明系统日志区（播报「获得 xxx」「需要青铜镐」等）、中央准星与蓄力/破坏进度条、顶部居中当前地图名、顶部 Toast 提示。**驾驶飞机时，底部快捷栏（物品栏）整条隐藏，左上角状态块（姓名 + 生命爱心 + 饥饿）与顶部居中世界名一并隐藏，右上角小地图（指南针）与模式徽章隐藏、仅保留天数·时钟·天气行**（经 `Events.aircraft_ride_changed` 单点联动；D-046 起状态块重新隐藏——飞行中玩家就是飞机本身，生存读数是徒步身份，顶部居中与左上角分别让给飞行面板和仪表读数；数值刷新不经 riding 门控，下机即最新值；Toast 同时挪到底部居中，不再压飞行面板）。驾驶飞机时准星区切换为飞行仪表（见 9.8）：按视角分座舱玻璃 HUD / 追尾四角 HUD + 小地图 /（H 键）详细 12 仪表清单，含空速 / 离地高度 / 油门 / 燃油 / 失速·超速·过低·低油告警与闪烁横幅；顶部居中的飞行面板卡片（空速/失速参考/离地/油门条/视角/发动机/失速行）常驻，其下方挂起飞教练区（见 9.9）；地图(M)/回放(P) 时让位于战术地图与回放覆盖层。

## 14. 生存机制细节

- **生命**：20 点 = 5 颗心。受跌落、怪物攻击、饥饿伤害。
- **饥饿**：0~20，站着不动 **0.02/秒**（满值可撑 1000 秒 ≈ 1.7 个白天），冲刺额外 **0.06/秒**；归零后每 **5 秒**扣 1 点血。吃到 20% 以下时 HUD 提示「该吃东西了」。
- **掉血播报**：每次扣血都带来源广播（饥饿 / 摔落 / 生物名 / 箭矢 / 卡住），HUD 以 Toast 显示「💔 被僵尸打中了 −2（剩 8）」——看不见原因的掉血只会被当成 bug。
- **受击无敌帧**：被生物命中后 0.5 秒内的再次命中全部忽略，避免一群怪在同一瞬间把血条清零。
- **跌落伤害**：落差 3 格内免伤，超过部分按系数扣血。
- **昼夜**：白天 10 分钟；入夜后前 40% 夜程完成变黑（环境光压至 0.08、天幕深蓝近黑），整夜保持；方向光与环境光/天幕同步调制。
- **防卡死保护**：脚部与头部同时处于实心方块内且持续超过 3 物理帧 → 判定嵌入地形，瞬间死亡并在安全点重生（向上扫描「两格空气 + 实心底」的落点）。创造模式同样生效（否则无敌会卡到死循环），且不消耗不死图腾。
- **不死图腾**：受致命伤时自动消耗 1 个，回复半血。
