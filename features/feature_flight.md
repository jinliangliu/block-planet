## 1. 概述

玩家在世界里放置/拼装一架轻型单发固定翼飞机，登机后进入**第一人称座舱**，用键盘当操纵杆（方向键拉杆压杆）、鼠标环顾驾驶员视角（D-070），完成起飞 → 巡航 → 进近 → 降落。座舱内所有仪表与内装是**一块屏幕最上层的 2D 像素绘制**（不用 3D / ViewportTexture），风格参考战雷（War Thunder）老式战机仪表：黑盘面 + 白色硬边刻度 + 琥珀指针 + 金属仪表板。

一句话概括现状：**气动是真的（简化真实气动模型），座舱是画的（纯 2D 覆盖层）**。

关键设计取向：

| 取向 | 落地方式 |
|---|---|
| 儿童友好 | 辅助稳定三档（默认"标准"=半开）、失速留 35% 残余升力、警告带蜂鸣码与动作词、起飞教练四步阶梯 |
| 看得懂打得准 | 气动只保留核心：升力随攻角线性→失速掉落、诱导阻力随 CL²、密度随高度衰减、操纵权限随动压下降 |
| 数据单一来源 | `AircraftFlight`（气动）→ `FlightInstruments`（仪表加工）→ 座舱 2D / 追尾四角 / 3D 面板 / 战术地图共用同一份读数 |
| 座舱可信 | 2D 像素内装（风挡支柱 / 侧 console / 磨损 / 螺钉）+ 战雷式圆盘仪表 + 飞行指引十字 |
| 移动端可达 | 触屏飞行层（左下摇杆 + 右下油门 + 方向舵/刹车 + 右上按钮排） |

⚠️ 本作在同类里的位置、以及"学谁 / 不学谁"，见 **§16 横向对比**。

## 2. 玩家流程

```text
进图（探索模式赠机 / 机场跑道待发）
→ 走近飞机按 F 登机
→ 【自动】相机复位到第一人称座舱（D-049），满油、襟翼回 0 档
→ 起飞教练接管：① 按 F 点火 → ② 按 W 推满油门 → ③ 滑跑到抬轮速度 → ④ 按 ↑ 抬轮
→ 离地爬升（飞行指引十字给 10° 爬升指令，爬到 100 m 段内保持；D-072）
→ 巡航（十字只导航向；M 键战术地图看位置）
→ 接近机场（≤400 m 转进近，十字给 3° 下滑道指令，世界里有地面箭头 + 下滑道双轨）
→ 接地滑跑（空格刹车）
→ X 下机（自动熄火、油门锁 0）
→ 坠机时：弹射生还即【自动】退出座舱界面、回到本图初始停机坪满油待发（D-056）；
  卡住 / 想手动重开再按 Y（D-039 一键归位，语义相同）
```

## 4. 飞行物理与气动

### 4.1 世界尺度与整机尺寸

| 项 | 值 | 出处 |
|---|---|---|
| 1 格 | 1 m | D-062/D-063 |
| 机身长 / 翼展 | 10.2 m（约 10.2 格）/ 24 m（24 格） | `aircraft.gd` 头注释 |
| 碰撞盒 | 6.6 × 4.8 × 15.6 m（即 6.6 × 4.8 × 15.6 格） | `COLLIDER_SIZE` |
| 机轮离地净空 | `AircraftModel.GROUND_CLEARANCE` | 与机模共用 |
| 座位偏移（脚底） | `(0, 1.35, -2.8)` | `SEAT_OFFSET` |
| 座舱眼位 | `(0, 1.15, -3.4)` | `AircraftCamera.COCKPIT_OFFSET` |

⚠️ 碰撞盒只包机身，**翼展 24 m 不参与碰撞**（否则一路刮蹭树冠屋檐）。且碰撞盒**恒定世界水平**（`_pin_collider`），不随机体姿态转——这是 D-048 的结论：随机体转会把机尾/翼尖埋进地面，起降全都变成坠毁。姿态旋转只作用于外观与读 `global_transform` 的下游（相机 / 仪表 / 座位 / 录制 / 流式窗口）。

### 4.2 气动常量（`aircraft_flight.gd`）

| 常量 | 值 | 含义 |
|---|---|---|
| `GRAVITY` | 9.80665 | |
| `SEA_LEVEL_DENSITY` | 1.225 kg/m³ | |
| `DENSITY_SCALE_HEIGHT` | 8500 m | 密度指数衰减标高（8500 m 处约 37%） |
| `CL_ALPHA` | 5.0 /rad | 升力线斜率（3D 机翼实测低于 2π） |
| `CL_MAX` | 1.6 | 升力系数上限 |
| `STALL_ALPHA` | 0.32 rad ≈ 18° | 临界攻角（= CLmax / CLα，自洽） |
| `STALL_WARN_ALPHA` | 0.27 rad | 失速预警 |
| `CD0_BASE` | 0.06 | 零升阻力基值 |
| `INDUCED_K` | 0.052 | 诱导阻力因子 |
| `SIDESLIP_DRAG` | 0.35 /rad | 侧滑附加阻力 |
| `THRUST_DENSITY_EXPONENT` | 0.7 | 螺旋桨推力随密度衰减指数 |
| `VNE` | 55.0 m/s（198 km/h） | 结构极限速度，超出即解体 |
| `FLAP_VFE` | 30.0 m/s | 襟翼标速（超速放襟翼只提示不硬拦） |
| `ROLL_RATE_MAX` / `PITCH_RATE_MAX` / `YAW_RATE_MAX` | 2.2 / 1.1 / 0.55 rad/s | 三轴最大角速度 |
| `RATE_RESPONSE` | 4.5 /s | 舵面响应时间常数倒数 |
| `CONTROL_Q_REF` | 250 Pa | 操纵权限基准动压 |
| `CONTROL_AUTHORITY_MIN` | 0.12 | 低速杆效下限（杆变软但不失效） |
| `YAW_STABILITY` | 1.1 | 风标稳定性（机头自动朝向来流） |
| `TURN_COORDINATION_RATE` | 0.5 | 坡度自然带出偏航（不踩舵也能协调转弯） |
| `PITCH_LIMIT` | 1.45 rad ≈ 83° | 空中的俯仰限位 |
| `GROUND_PITCH_MAX` | 0.21 rad ≈ 12° | **地面**机轮限位（可抬头离地，不能翻跟头） |
| `CRASH_IMPACT_DV` | 7.0 m/s | 单帧速度损失超此值即解体 |

**"压坡度就会转弯"没有额外公式** —— 升力方向取 `basis.y` 去掉速度分量，滚转时升力自然被掰向侧向，转弯是升力侧向分量的结果。

**失速后保留 35% 残余升力**（`lift_coefficient`）：避免"一失速就直接坠地"，给儿童留出改出余地。

### 4.4 零件聚合（`Airframe.aggregate`）

整机不再是"烘焙好常数的飞机"，而是**由零件拼装、物理按零件求和**：

- 随零件变化：总质量、翼面积、推力、零升阻力、燃油容量、油耗、重心（质量加权）、升力中心（面积加权）
- 结构限速 VNE = 所有零件 `vne_limit` 的**下限**
- 跨零件共享（保持静态）：翼型曲线、大气、操纵品质

零件表（`part_registry.gd`）：

| 零件 | 质量 kg | 推力 N | 升力面积 m² | 燃油 L | 油耗 L/s | 成本 |
|---|---|---|---|---|---|---|
| 机身 fuselage | 119 | — | — | — | — | 0 |
| 机翼 wing | 30 | — | 12 | — | — | 5 |
| 尾翼 tail | 8 | — | 2 | — | — | 3 |
| 发动机 engine | 45 | 1650 | — | — | 0.10 | 12 |
| 螺旋桨 propeller | 6 | — | — | — | — | 4 |
| 起落架 gear | 12 | — | — | — | — | 3 |
| 油箱 fuel_tank | 20 | — | — | 55 | — | 4 |
| 涡轮发动机 turbine | 55 | 1750 | — | — | 0.18 | 30（绿宝石解锁） |
| 长航程机翼 long_wing | 42 | — | 18 | — | — | 20 |

默认套件的聚合结果与旧标定逐项一致，所以**换零件不改变默认手感**，只改变"造得大飞得远"这类可预期的量（2 油箱 = 110 L）。

### 4.5 燃油 / 发动机 / 襟翼

| 项 | 值 |
|---|---|
| 燃油容量 | 聚合值（默认 55 L）；**出生 / 装配 / 每次登机都补满**——油是"这一程"的资源，不是耐久 |
| 油耗 | `fuel_burn × 油门`（默认 0.10 L/s），怠速不耗，熄火不耗 |
| 续航 | 满油满油门 9.2 min；半油门巡航 18.3 min |
| 耗尽 | 自动熄火（油门锁 0、无推力），**舵面仍可滑翔降落**——不坠毁不爆炸 |
| 低油警告 | ≤20% 触发，>25% 才清除（滞环防边界抖闪） |
| RPM | `600 怠速 + 2100 × 平滑油门` = 0..2700；τ = 0.4 s；熄火后自旋减速到 0 |
| 襟翼 | 3 档（0 洁净 / 1 起飞 / 2 着陆），Z 键循环；CL 倍率 1.0 / 1.25 / 1.5，CD 加数 0 / 0.010 / 0.022 |
| 起落架 | 固定式，恒放下锁定（绿色灯） |

### 4.6 辅助稳定（`FlightSettings`）

三档，默认**标准 = 半开**：

| 档 | roll_level | yaw_damp |
|---|---|---|
| 关闭（硬核） | 0.0 | 0.0 |
| 半开（标准） | 0.9 | 0.8 |
| 全开（休闲） | 1.8 | 1.5 |

规则：
- **只在松杆时接管**（三轴杆量 <0.05 才生效）；玩家一压杆，辅助立刻完全让位。
- 只做**坡度摆平 + 偏航阻尼**。**刻意不做俯仰自动配平**——那会与爬升/失速这类正常俯仰机动对抗，也会搅乱"满拉杆逼失速"的主动改出。
- 另有**自动改平**（双击左键，2 s 内以增强增益把坡度与俯仰一并摆平），与松杆配平刻意区分：它含俯仰，且增益取 `max(辅助档, 0.9)×2.5`，硬核档下也能生效。

### 4.7 地面物理

- 轮胎抓地：水平速度被拽向机头方向（`GROUND_GRIP = 3.0 /s`）
- 滚动阻力 0.6 m/s²；刹车 6.0 m/s²
- 前轮转向 `STEER_RATE = 0.8 rad/s`，**按速度衰减**（高速靠气动舵面）
- ⚠️ 地面时气动层**不叠**杆量偏航：真实飞机地面滑跑方向舵无气动效用，转向靠前轮（修复前实测 ≈77°/s，轻点方向舵就冲出跑道）

## 6. 视角系统（`AircraftCamera`）

六种模式，后视 / 自由观察 / 地图 / 回放都是**覆盖层**，退出时回到底层模式（`_base_mode`，只有座舱 / 追尾两种）。

| 模式 | 参数 |
|---|---|
| FIRST_PERSON | 眼位 `(0, 1.15, -3.4)`，视线在机头上仰基础上再抬 1.1 m @10 m 前视 |
| CHASE | 距离 13 m（滚轮 8..20）、高 4.5 m、前视 lead 2 m |
| REAR | 距离 7 m、高 2.6 m，回头拍机体 |
| FREE_LOOK | 座舱内环顾 / 追尾球面环顾；灵敏度 0.0025 rad/px，俯仰限 ±1.1 rad（偏航限 ±2.4 rad 见下） |
| MAP | 高 60 m（20..120），north-up |
| REPLAY | 位姿由 `FlightReplay` 直写 |

通用：

- **阻尼**：远距 4.0 /s（τ≈0.25 s，模式切换柔和）、近距 25.0 /s（τ≈0.04 s，55 m/s 全速只拖影约 2 m）；指数阻尼永不过冲
- **FOV**：飞行 82°（战术地图 70°）。75°→82° 是"视场不够宽"的定量化落地：座舱里被仪表板与舱框一挡，窄视场只剩一条缝
- **追尾 / 后视抑制滚转**（地平线稳定，防晕）
- **防穿模**：10 Hz 射线，命中则拉近到命中点前 0.5 m
- **镜头抖动**：幅度 0.05 m，按油门/空速缩放，可在设置里关
- **登机默认第一人称**（`reset_to_cockpit`，同时写 `_mode` 与 `_base_mode`——只写 `_mode` 会被覆盖层退出掀回追尾）
- **座舱内鼠标 = 驾驶员环顾（D-070）**：`apply_look_delta` 对 FIRST_PERSON 生效，与座舱底自由观察共用 `_cockpit_look_dir` 同一条视线式子（机头 + 天地线抬升 + 环顾偏移；偏移为零时逐位退回 D-050 原方向）。**鼠标不再接飞机**（D-034 鼠标操纵杆已整体拆除，`add_mouse_motion` / `_stick` 删除）——飞机杆量只来自键盘（触屏来自 HUD 摇杆），「想操纵」与「想转头」不再抢同一只手。偏航限 ±2.4 rad：座舱里是「驾驶员的头」不是轨道相机。**座舱内视不自动回正**（gaze 停在落下的地方；回正归中键 `recenter()` 与下次登机），`auto_recenter`（松手回正）只管 V / 按住右键的自由观察覆盖层退出那一刻；切回追尾/后视/地图时偏移按 `RECENTER_RATE` 指数归零

## 7. 座舱设计（重点）

### 7.1 结构性结论：座舱是「2D 画的 + 3D 建的」双层

> **D-065 起本节结论已改写**。原结论是「座舱是画的，不是建的：`Aircraft` 没有座舱内装几何，环顾时框不动、低头看不到仪表台」（U-1 结构性项）。D-065 用 L1 环绕框 + L2 3D 仪表台 + L3 杆手补上了 3D 那一层；下面的「三步」里第 1、2 步不变，第 3 步从「唯一实现」变成「像素读数层」。

第一人称 = **两层叠加**：

1. **隐藏整机外观**（`set_cockpit_interior(true)`）——眼位 `(0, 1.15, −3.4)` 落在机身盒内部，机翼（y 1.335..1.785）正压视平线。不隐藏的话第一人称先看到自己的机翼横贯全屏。
2. **相机放进机身内**（见 §6），座舱两模式位置**刚性吸附**眼位（D-065，见 §7.9）。
3. **两层画座舱**：
   - **2D 像素层** `CockpitInstruments`：屏幕空间的框体 + dash + 六件仪表 + 磨损，`draw_rect` / `draw_colored_polygon` / `draw_circle(antialias=false)` 硬边像素。锚屏幕、**不参与 3D 相机**，尺寸纪律见 §7.8。
   - **3D 内装层** `CockpitInterior`（39 盒 / 9 共享材质，D-065）+ `CockpitPanel`（3D 仪表台）：挂机体、参与相机，所以**环顾时有视差、低头能看到仪表台与杆手**。
4. **可见性极性相反**（写死在代码里，勿"统一"）：
   - `CockpitInterior.visible = _base_visible and active`（`active` = 座舱内视）
   - `CockpitPanel.visible = _base_visible`（非蓝图即显）——正对前方时它的投影落在 2D dash 矩形内被完全遮住，这就是「重合」的字面含义；**收益点是环顾与低头，不是正视**。

由此推出的必然结果：2D 簇在自由观察 / 低头时按 `flight_instrument_hud.gd:181`（`_cockpit.visible = fp`）整体让位，由 3D 仪表台接管；正视时 2D 簇仍是权威读数层。蓝图试飞机无座舱罩，按契约**两层都不建**。

### 7.3 仪表板尺寸与自适应

```gdscript
const REF_VP     := Vector2(1280.0, 720.0)   # 基准视口
const SCALE_MIN  := 0.70                     # 太小刻度糊成一片
const SCALE_MAX  := 2.80                     # 太大面板压掉视野

static func ui_scale(vp) -> float:
    return clampf(minf(vp.x / 1280.0, vp.y / 720.0), 0.70, 2.80)
```

**为什么要自适应**（这是 D-052 的核心修复，也是"尺寸不合理"的真实根因）：
项目用 `stretch=canvas_items + aspect=expand`，逻辑视口**宽恒 1280、高度随宽高比在 590~720 之间漂移**（19.5:9 手机实测 1280×590）。固定像素下仪表占屏高会从 21% 漂到 26%。改为"基准视口 + 等比缩放 s"后，任何宽高比都锁在同一比例（实测离散度 **0.0000**）。

⚠️ 一个已纠正的误判：`--resolution 1920x1080` 实测传给脚本的仍是 1280×720，`canvas_items` 下逻辑视口恒定。**真实漂移来自 `aspect=expand` 的高度，不是分辨率**。

布局基准（s=1，全部自屏幕底边起算）：

| 常量 | 值 | 说明 |
|---|---|---|
| `MARGIN_B` | 12 | 簇底距屏幕底 |
| `GAUGE_SZ` | 152 | 地平仪外径（最主仪表，居中） |
| `SIDE_SZ` | 140 | 空速/高度盘外径 |
| `BEZEL` | 9 | 金属压环总厚（含 3px 受光边） |
| `GAUGE_GAP` | 20 | 盘间距 |
| `TAPE_W` / `TAPE_H` / `TAPE_STRIP` | 600 / 56 / 34 | 航向带（3 上条 + 34 刻度窗 + 数字窗） |
| `TAPE_PPX` | 5.0 | 像素/度（600 px ≈ ±60° 视野） |
| `DASH_PAD` / `DASH_LIP` | 18 / 4 | 底板左右 padding / 顶沿受光条 |
| `BAR_W` | 32 | 油门/燃油竖条宽 |
| **`GAUGE_K`** | **2/3** | **盘排竖向压缩比（D-053，用户圈注"高度缩小 1/3"）** |
| `PITCH_MAX` | 60° | 俯仰钳制（超过截断、不无限滚动） |
| `SPD_MAX` / `ALT_MAX` | 250 / 1000 | 盘量程 |
| `BLINK_MS` | 600 | 闪烁周期（与警告横幅一致） |

⚠️ `GAUGE_K` **只压盘排本身**（表盘直径、盘间距、簇底留白、竖条宽），航向带与底板宽度不动——宽度由 `TAPE_W` 决定，用户只要求高度。

**盘内细节按"盘径 / 设计稿尺寸"取尺**（不乘 `ui_scale`）：
```gdscript

```
否则盘缩到 2/3 而字号、压环、指针原地不动，会糊出盘外。

### 7.4 六件仪表（逐一）

#### ① 地平仪（主表，居中，最大）

- **圆盘**：三层金属压环（受光边 → 暗部 → 盘面）+ 45° 玻璃反光（alpha 0.035）
- **天地**：「圆 ∩ 地平线半平面」裁剪填充（`clip_seg_circle` + `clip_poly_half` + `circle_poly`），天地在圆内截断
- **俯仰** → 天地垂直偏移；**横滚** → 整个天地旋转；**±60° 钳制**，超过画面截断不无限滚动
- **俯仰阶梯** `LADDER = [10°, 20°, 30°]`：只画盘缘两侧（不横贯盘面抢读数），用 `clip_seg_circle` 裁进圆
- **横滚刻度** `ROLL_TICKS = [0, 10, 20, 30, 45, 60]`：沿盘内缘
- **飞机标记**：琥珀色、固定不随姿态动（这是"飞机符号"，天地动、飞机不动）
- 数字锚点贴在阶梯线内侧（`lseg[1].lerp(lseg[0], 0.14)`）

#### ② 空速（SPD，主表左侧）

- 270° 环形刻度（25 格）+ 琥珀指针 + 中心轴
- 量程 0..250 km/h；超量程指针停满偏，数字窗永远显示真实值
- **盘下数字窗**（0.62 宽 / 0.28 高）：数字左、单位右，同一行（放到盘外会飘到板上像无主文字）
- 超速 / 失速 / 接近失速 → 告警配色
- 标签移为"窗标题"（数字窗上方 3px），不与指针重叠

#### ③ 高度（ALT，主表右侧）

- 与空速同款，量程 0..1000 m（儿童向飞行几乎全在 300 m 以下，取 2000 会让指针长期贴着最低刻度不动）
- **高度过低（`alt_warn > 0`）→ 数字变红并按 600 ms 闪烁**

#### ④ 航向带（压在盘排上方）

- 上下金属条 + 内窗 + **两端六级渐隐**（连续不跳变）+ 琥珀指针（竖线 + 倒三角）+ 带下数字牌
- 左右固定基准小三角
- 359°→0° 取模连续
- 5 px/度，600 px ≈ ±60° 视野

#### ⑤ / ⑥ THR / FUEL 竖条

- 贴 dash 内沿（填掉盘排两侧空洞）
- THR = 油门指令值（0 时暗）；FUEL = 燃油比例（低油变红）
- 填充色比指针暗一档 `Color(0.86, 0.62, 0.18)`

### 7.5 飞行指引十字（Flight Director Cross，D-054）

座舱里现在有**两个十字**，不能混：

| | 外观 | 含义 | 动吗 |
|---|---|---|---|
| **准星**（D-034 既有） | 白色细十字，臂长 36，alpha 0.6 | 机头**现在**指哪 | 固定屏幕中心 |
| **飞行指引十字**（D-054） | 彩色粗十字 + 端帽 + 黑描边，臂展 70 | 机头**应该**指哪 | 随偏差偏移，限幅 ±120 px |

**操作语义 = 真实 FD command bars：把准星套进指引十字 = 沿正确航径飞。**

导引律：

| 常量 | 值 |
|---|---|
| `GAIN_PX_PER_DEG` | 11.0（偏差 1° → 偏移 11 px） |
| `MAX_OFF` | ±120 px |
| `DEV_CLAMP` | ±12°（单轴偏差角钳制） |
| `GLIDE_DEG` / `CLIMB_DEG` | 3°（进近下滑）/ 10°（起飞爬升，D-072：原 8°） |
| `APPROACH_DIST` | 400 m |
| `ROLL_AGL` / `CLIMB_CEIL` / `TAKEOFF_DIST` | 2 m / 100 m / 250 m（D-072：原 60/200） |
| `CAPTURE_DEG` / `WARN_DEG` | 1.5°（绿 + 四角括号）/ 12°（红） |
| `ARM` / `ARM_T` / `GAP` / `CAP_W` | 34 / 3 / 11 / 15 |
| `BRACKET` / `BRACKET_L` / `ARROW` | 46 / 11 / 15 |

- **水平**：目标方位 − 当前航向（复用 HSI/CDI 的 `nav_dev_deg`，正 = 目标在右 → 十字右移）
- **垂直**：相对 3° 下滑道平面的高度偏差，`gs_y = target.y + d·tan3°`，`dev = −atan2(craft.y − gs_y, d)`（高于下滑道 → 低头追回）。分母有 30 m 下限，防止贴脸时 atan2 发散。

五个模式：

| 模式 | 判据 | 引导内容 |
|---|---|---|
| OFF | 无导航目标 / 空速 <10 km/h | 不显示 |
| ROLL | AGL < 2 m | 锁起飞航向，不引导俯仰 |
| TAKEOFF | AGL <100 m 且 升降率 >1 m/s 且 距机场 <250 m | 锁航向 + 10° 爬升 |
| APPROACH | 水平距离 ≤400 m | 直飞目标 + 3° 下滑道 |
| CRUISE | >400 m | **只导航向，俯仰不干预**（避免被迫下降） |

⚠️ **TAKEOFF 必须靠"升降率 + 离地高度"判，不能靠距离**：起飞时机场就在脚下（d≈0），只按距离会立刻被判成 APPROACH 并引导下降——起飞瞬间被提示低头是最危险的错引导。

颜色三档（实测像素值）：绿 `(115,242,140)` / 琥珀 `(255,184,51)` / 红 `(242,76,66)`。
标签给**动作词**（左转 / 右转 / 掉头 / 抬头 / 低头）而非模式名——玩家看得出该往哪修。
超量程时在十字**外侧**补同向箭头（画在臂内会被自己盖住）。

目标复用既有的 `set_navigation`（HSI / CDI / 3D 标注 / 十字永远同源），`main.gd` 零改动。

**D-071 让位**：失速教案（StallCoach）占用教练区期间，指引十字**整体退场**（只锁 `visible`，`refresh` 照跑、导航目标不丢），教案收尾瞬间自动归位。理由：失速时「掉头」（压坡度转弯）与教案「按【↓】低头」是**实时行为冲突**（坡度加速失速），进近段「抬头」更与「低头」字面相反——儿童一次只听一个声音，D-069 让位范式（横幅撤、卡片行删、起飞教练让位）自此补全到第四个通道。HSI/CDI/小地图/3D 标注不退场（无文字指令，玩家始终知道目标在哪）。

### 7.7 3D 座舱面板（`CockpitPanel`，第一人称与 2D 簇重合）

**几何由 2D dash 的像素矩形反解**（D-065），四个常量是单一事实源，`CockpitInterior` 的承托板尺寸全部派生自它们：

| 常量 | 值 | 说明 |
|---|---|---|
| `PANEL_W` / `PANEL_H` | 0.98 / 0.215 m | 反解自 720p 下 2D dash 板矩形 |
| `PANEL_POS` | `(0, 0.75, −4.15)` 机体局部 | 距眼 0.85 m |
| `PANEL_TILT_DEG` | −27.8° | 面板法线朝眼 |
| `VP_SIZE` | 768 × 168 @ 30 Hz，不透明 | SubViewport 内容 |

- 材质必须 `shading_mode = UNSHADED` + `albedo_texture = _subviewport.get_texture()`（**直接引用，不用 `viewport_path`**），且**带纹理一次成形**——先挂网格后补纹理编出的「无纹理」变体不会重编译，表现为满屏白（D-065 白屏事故）。
- 盘面：上排 4 圆（空速 / 姿态 / 高度 / 航向）+ 下排 3 圆（转弯协调 / 升降率 / HSI），均 92×92 @ y=10、x=8+110i；底部 4 条 LCD（离地 / 转速 / 燃油 / 襟翼·起落架）175×48 @ y=108、x=10+191i。
- `PANEL_*` 与 2D 簇的贴合容差：四角投影目标 TL(373.7,572.1) TR(906.3,572.1) BL(323.7,726.8) BR(956.3,726.8)，实测偏差 **0.2~0.3 px**（`cockpit_align_probe` 软断言 ±12 px）。
- **可见性（D-065 反转）**：第一人称即显示；正视时被不透明 2D 簇完全遮住 → **不改变任何 2D 观感**，只在环顾/低头时兑现价值。蓝图试飞机按契约不建几何。

承托板（`CockpitInterior` L2 的 12 盒：板 + 上/下暗缝 + 下唇 + 6 螺钉 + 2 支架）的四周边距 `DASH_RIM = 0.05`，板顶沿藏在 2D dash 带内（549 > dash 上沿 538.67）。抖动口径见 §7.10。

### 7.8 座舱尺寸演进（纪律）

| 版本 | 变化 | 主表 / dash 占屏高 |
|---|---|---|
| D-047 | 首版方窗仪表 | — |

### 7.9 座舱相机：位置刚性吸附（D-065，R1 缺陷修复）

座舱两模式（`FIRST_PERSON` / 自由观察且底层为座舱）下，`AircraftCamera._process` 不再走位移阻尼：

```gdscript
if is_cockpit_view():
    global_position = target.origin          # 刚性吸附眼位
else:
    var dist := global_position.distance_to(target.origin)
    var rate := lerpf(RATE_FAR, RATE_NEAR, clampf(1.0 - dist / TRANSITION_DIST, 0.0, 1.0))
    global_position = global_position.lerp(target.origin, _damp_rate(rate, delta))
```

**为什么必修**：指数阻尼对匀速目标的稳态滞后 = v/rate，`dist > TRANSITION_DIST(2 m)` 时 rate 只有 `RATE_FAR = 4` → 50 m/s 滞后 12.09 m、55 m/s 滞后 13.30 m。3D 面板距眼 0.85 m，滞后十几米会把面板缩到 1/14，「与 2D 簇重合」在数学上不可能。姿态仍走 slerp（旋转平滑是舒适度需要，与位置无关）。

**代价（已定夺接受）**：按 C 进座舱是**硬切**（原 1.5 s / 16 m 的飞入动画取消），出座舱仍平滑。`flight_view_probe ④` 因此拆成两条：进 ≥90%（刚性）、出 <95%（非硬切）。

### 7.10 抖动口径（D-065 定夺）

`SHAKE_AMP = 0.05` 在 0.85 m 处 = **±20 px（巡航）/ ±36.6 px（满油门）**。判定：**3D 内装随相机抖、2D 簇不抖**是正确观感——座舱是「世界」，HUD 是「玻璃上的读数」；玩家可用设置里的「镜头抖动」关掉（关 = 对齐最准，开 = 生命感）。`SHAKE_AMP` 维持 0.05 不动；承托板靠「板顶沿藏进 2D dash 带」把峰值残余压到 ≤27 px 深色板沿呼吸（旧方案 48.3 px）。

### 7.11 一次性教学提示（U-9，D-069）

D-065 补了 `CockpitPanel` 之后，第一人称**低头能看到 3D 仪表台**——但儿童玩家不知道这件事，于是有了一条一次性的 Toast：`💡 低头可以看 3D 仪表台`。

| 维度 | 取值 / 判据 |
|---|---|
| 触发条件（全部满足） | 非触屏 + 非蓝图试飞机 + 座舱视角（含自由观察底层为座舱）+ `AGL ≥ 15 m` + 教练区空闲 + 未看过 |
| 通道 | Toast（覆盖式，2.2 s 保持 + 0.6 s 淡出）——**不占教练区**，避免与起飞/失速教案抢同一块地 |
| 一次性 | **看过才消耗**（D-069 F-13）：命中只记内存态 `pending_id` 不落盘；Toast tween 自然结束时回调 `confirm_shown()` 才 `mark_seen` 落盘；被后续 Toast 顶掉（tween 被 kill、`finished` 不发）则 `cancel_pending()`，下次条件满足时重演 |
| 为什么不用「投递即消耗」 | Toast 是覆盖式的（HUD 共 11 处 `_show_toast`），提示投出去 2.8 s 内若被坠机「💥」之类顶掉，旧实现会把这条一次性提示**永久消耗**，玩家再也看不到 |
| 位置 | 驾驶时按 `CockpitInstruments.metrics()` 的 **dash 顶沿**取相对位（贴顶沿上方 8 px，落进风挡开口）；D-053 放大仪表簇后，旧固定锚点（y H-52…H-20）落回了 2D 仪表台盘排内部、被画在上层的仪表盘糊住。**anchor 同在屏底（1.0）时 offset 必须为负**、按「距屏底多远」计量（`offset_bottom = dash_top − 8 − vp.y`）——正值写法（按距屏顶计量）会把 Toast 整块推出屏幕外 |
| 持久化 | `user://flight_teaching.json`，`{"seen": [id, ...]}` 数组形状 + **tmp→rename 原子写** |
| 15 m 的依据 | 起降滑跑阶段教练区正忙、且「低头看仪表」在起降期是危险建议；15 m 与 `TakeoffCoach.TAKEOFF_ALT` 同值，正好接在「🎉 起飞成功」之后 |

三个设计取舍：

- **不并进 `settings.json`**：恢复默认会把它清掉。可接受的后果是「提示复发」，不可接受的是「别处被牵连」，故独立文件。
- **读档宽容**：文件缺失 / JSON 损坏 / 顶层不是对象 / `seen` 不是数组 / 条目不是字符串，一律按「什么都没看过」处理——最坏后果只是提示复发（无害），但坏文件绝不能让 HUD 崩。
- **触屏缺口记 U-12**：触屏没有鼠标环顾手段，「低头」无从谈起，本次直接不投，不发明半成品手势。

## 8. 界面系统（非座舱）

### 8.1 追尾 / 后视 / 环顾

屏幕四角 HUD（18px 字 + 4px 黑描边）：

- 左上：空速 / 航向（超速或失速转红）
- 右上：高度 / 升降率
- 左下：油门 / 燃油（低油转琥珀）
- 右下：目标方位 / 距离
- 再右下：160×160 小地图（北朝上，中心三角 = 本机 + 航向，外圈 = 导航目标方位点）

### 8.2 HUD 详细模式（H 键，落盘）

左侧 12 行全读数：空速/失速余量、姿态、高度 MSL/离地、转弯率/协调、航向、升降率、HSI/CDI、雷达高度、转速、燃油、襟翼/起落架、警告。
默认关闭（儿童优先：信息少 = 不晕）。座舱视角下即便开着也隐藏。

### 8.3 战术地图（M 键，`FlightTacticalMap`）

- `CanvasLayer`，层 20（压在 HUD 与面板之上）；打开不影响飞行（只读世界与飞机状态）
- 打开时一次性采样：33×33 粗网格 ±180 m（近 45 m 读真实方块、远用与 `World` 同源的噪声估算）+ 跑道细扫 ±64 m（步长 4 m，识别 COBBLESTONE 顶面簇定位机场）
- 之后 `_draw()` 只画缓存，零世界查询；本机飞出 130 m 才重新采样
- 每帧零分配（值类型 + 预分配点阵）
- 鼠标模式切换、滚轮缩放；触屏跳过鼠标模式

### 8.3b POI 直飞（D-073，P3）

绕场任务之外的第二种导航玩法：把世界真实设施登记成可直飞兴趣点，用 `RouteGenerator`（地形感知航线）规划一条净空航线，交给 `RoutePlan` 自由飞行接管，并画出世界环廊 + 战术地图航线 + HSI 导航。

- **数据来源 = 建造器真实落点**：`main` 在场景就绪时登记（`PoiRegistry`，含 `KIND_NAMES` 中文表：机场 / 降落场 / 村庄 / 港口），**不取** `REGION_LANDMARKS` 经纬度地标（玩家活动范围仅原点数百米，真实比例换算落点无区块、世界内零地标建筑）。
- **入口 = 任务面板 POI 区**：`MissionPanel` 新增「直飞兴趣点（POI）」区块，每个 POI 一张卡 + 「直飞」按钮；点按 → `hud.poi_flight_requested` → `main.start_poi_flight(poi_id)`。
- **航线规划**：`start_poi_flight` 取本机世界坐标（`_world.to_world(craft.global_position)`）→ `RouteGenerator.plan_between(_world, from, to, 30.0, 24)`（沿直线采样 `get_surface_height`，**不依赖区块加载**，不取 `get_block`）；丢弃首点（起飞机动点，避免首帧空推进），末点 `kind=DEST`、`name=POI` 标题。
- **导航接管**：`RoutePlan.advance` 按机体位置自由推进（与任务绕场 `set_current_index` 对齐判定**互斥**——任务判定真相只在 `MissionManager`）；捕获 `DEST` → `_clear_poi_route(true)`（清环廊 + 标注 + 战术地图、复位导航回机场锚点）。
- **走廊可视化**（`flight_markers.gd`）：沿规划航线（渲染坐标，统一 `to_render` 一次）每 ~40 m 一个青色垂直环（torus，洞轴对准航向 `atan2(dir.x,dir.z)`），半径取净空一半、封顶 48 环；战术地图复用 `set_tactical_route`（世界坐标）。环廊随 `WorldAnchor` 挂 `main`，浮动原点搬迁自动平移。
- **互斥与让位**：任务进行中拒绝开始 POI（`Events.notice` 提示）；POI 航行中任务被启动 → `_physics_process` 导航分支使 POI 自动让位（落回任务导航）；下机 / origin 搬迁 → 清 `_poi_nav_key` 促下一帧重注入。
- 探针 `poi_route_probe`（24 断言）覆盖注册表 / RouteGenerator 集成 / `RoutePlan.points()` 拷贝 / 环廊几何 / 管线。

### 8.4 飞行卡片（`hud.gd`）

顶部居中（追尾）/ 左上（座舱），236 px 宽。内容：标题、空速（含失速速度）、离地高度、油门条（█/░ 字形）、视角、发动机状态、失速行、起飞教练区。
坠机时隐藏（`is_wrecked()`）。

### 8.5 坠机与救援（D-039 / D-056）

解体（超速 / 撞击 Δv ≥ 7 m/s）→ `wreck()`：喷碎屑、广播 `crashed(reason)`、**抛出乘员**（`exit_aircraft(CRASH_DAMAGE=6, reason)`）、残骸翻倒后 4 秒消散。

弹射后的界面复原（D-056，全部随 `aircraft_ride_changed(false)` 一次到位）：

| 项 | 行为 |
|---|---|
| 屏幕仪表 HUD | `hide_all()` 整层收起——tick 只在驾驶中驱动，不显式隐藏会冻结在座舱画面（用户实测病根） |
| 座舱 3D 面板 / 世界标注 | 释放并注销 |
| 飞行相机 | `set_active(false)` 让位，玩家相机恢复 |
| 飞行卡片 / 触屏飞行层 / 教练 | 收起 |
| 战术地图（M） | **代关**——它不锁输入且改了鼠标 VISIBLE，不关的话 M 键语义已变成开地图选择器，玩家再也关不掉 |
| 左上状态块 / 物品栏 / 小地图 / 模式徽章 / 时间行 | 恢复显示 |

**生还即自动归位**：`exit_aircraft` 在伤害结算之后发 `Events.aircraft_crash_survived(reason)`（判据 `damage > 0 and not _dead`），Main 延迟一帧执行 D-039 的 `reset_flight_experience`——残骸立即清除、停机位补/搬一架满油完好的飞机、玩家传送回初始出生点朝北正对飞机，Toast「💥 原因——已回到停机坪，满油待发。」

- **致死弹射不走自动归位**：死亡流程接管（墓碑 + 2.2 s 停顿 + 回出生点复活），坠机救援不抢戏。
- **弹射伤害照常扣**（6 点）：自动归位不得变成「免费重置」，探针 A13 钉死 `health == MAX_HEALTH - 6`。
- 卡住 / 手动重开仍按 **Y**（与自动归位同一函数，`notice` 文案不同）。

## 9. 引导与教学

### 9.1 起飞教练（`TakeoffCoach`，纯逻辑）

存在的理由（两个真实卡点，都是提示缺失而非物理错误）：
1. 登机时发动机**默认熄火**，熄火时油门锁 0 → "推油门飞机不动"，玩家不知道要按 F
2. 拉杆是 ↑/↓，而鼠标历史上只是座舱视角的操纵杆（D-070 起连这个也废了：鼠标只环顾驾驶员视角，飞机只由键盘/触屏操纵）→ 照旧文案晃鼠标毫无反应

四步阶梯（前一步没做完就不提示下一步）：

| 步 | 文案 | 说明 |
|---|---|---|
| ① | 按【F】启动发动机 | 地面/空中都要；闪烁提示 |
| ② | 按住【W】推满油门 | 或 Shift 一键推满；带进度条 |
| ③ | 继续滑跑加速 x / VR km/h | **VR = 失速速度 × 1.2**（跟着 stall_speed 走，不写死 50 km/h） |
| ④ | 轻按【↑】抬轮 | 速度够了才喊，避免早抬轮失速 |

离地 >15 m 报"🎉 起飞成功！"停留 3.5 s，之后返回空字典（HUD 收起教练区）；落回地面自动重新接管。
**失速故意不归教练管**——卡片失速行 + 全宽警告横幅都在报，教练再插一条会在顶部居中互相压字。

### 9.2 世界 3D 引导（`FlightMarkers`，仅追尾可见）

- 目标点：金色双环（贴地）+ 悬浮 `Label3D` 名称/距离（Y-billboard）
- 地面箭头：从进近起点沿跑道轴向列 6 个，间隔 40 m
- **3° 下滑道双轨**：从 250 m 外、高度 +13 m 处沿 3° 下降引向目标
- 距目标 <50 m 整体淡出（避免贴脸挡视线）

⚠️ D-052 修了一个从未生效的 bug：箭头高度原先取 `_ground_y()`（恒返回 0），而本工程地形通常在 y30~70——整列箭头埋在方块里，进近引导实际**从未可见过**。现在取 `entry.y`。

### 9.3 飞行指引十字

见 §7.5。与 3D 引导互补：3D 引导只在追尾看得见，十字段补的是座舱里缺失的"当前偏了多少"。

## 10. 警告系统

`FlightInstruments.alerts()` 八类九条，按优先级排序（同级内 WARNING 在 CAUTION 前）：

| id | 级别 | 文案 | 蜂鸣码 |
|---|---|---|---|
| terrain | 警告 | 前方有山！快拉升 | 880 Hz 急鸣三声 / 0.8 s |
| terrain_caution | 注意 | 前方有山，准备拉升 | 700 Hz 两声 / 1.5 s |
| stall_full | 警告 | 失速了！按【↓】低头 | 880/620 交替连续 |
| stall | 注意 | 要失速了，按【↓】低头 | 880 Hz 急鸣三声 |
| overspeed | 警告 | 飞太快！收油减速 | 660/520 双音循环 |
| fuel_empty | 警告 | 没油了！滑翔降落 | 330 Hz 长低音 |
| altitude_critical | 警告 | 快拉升！ | 700 Hz 两声 / 0.5 s |
| altitude_low | 注意 | 离地面太近！ | 700 Hz 两声 / 1 s |
| low_fuel | 注意 | 油不多了，准备降落 | 440 Hz 慢滴三连 |

规则：

- **同刻只播最高级那条的声音**，其余留灯光（防声音叠加成噪音）
- 低油滞环 20% / 25%
- 高度过低**刻意要求下沉率条件**（注意 AGL<15 且 VS<−2.5；警告 AGL<6 且 VS<−4；着地或 AGL>20 清除）——否则降落进近全程报警，儿童会学会忽略警报（警报疲劳比没警报更糟）
- **地形前视（D-072 P2b，GPWS 式，`TerrainWarning` 纯逻辑类）**：沿地速航迹外推 10 s、每 50 m 采一点（`min_ahead` = 预测最小余量；`rise` = 前方最高地表 − 脚下地表，同一采样器源头一致）。警告 = `min_ahead < 25`（绝对档，贴地平飞也拦）；注意 = `min_ahead < 40` 且 `rise > 20`（rise 条件是「山在迎面而来」与「只是在低空飞」的判别——没有它 FD 封顶 100 m 巡航会全程黄牌）；清除带 +20 m 滞环。三门控：未离地（AGL≤2）不报（滑跑正前方永远有「山」）、失速中让位 StallCoach（含 stall_warning，「按【↓】低头」与「快拉升」实时冲突，同 D-071 范式）、着陆下降段屏蔽（AGL<60 且 VS<−1.5）。高度场经 Callable 采样器由 hud.gd 登机时注入（`player.world_ref()` 惰性解析，换区不漂）；采样用 `get_surface_height`（精确面）， coarse LOD 网格对精确面的 overshoot（steep 区可达 ~17 m）是已记录的设计限制
- 蜂鸣码全部落在 330–880 Hz、单条 ≤1.2 s，避免刺耳；`user://voice/<id>.wav` 存在时优先播采样（预留语音资产接口）
- 主音量 0.22（提示不是警报）；设置里可整体关闭

## 11. 机场与降落场（`AirportBuilder`）

| 项 | 机场 | 简易降落场 |
|---|---|---|
| 跑道长 | 336 格 = **336 m**（D-091 在 D-040 的 112 格基础上延长 3 倍，112→336 格 = 168 m） | 32 格 = 32 m |
| 跑道宽 | 52 格 = **52 m**（翼展 24 m = 24 格全包，两侧各留 14 格余量） | 10 格 = 10 m |

## 11.5 亚洲分层地形（D-055：喜马拉雅 / 青藏高原 / 长江黄河）

用户：「完善地图（非选择器）扩大规模和地图细节，以亚洲地貌举例，增加区域特有标志性自然景观，如喜马拉雅山脉、青藏高原、长江、黄河、昆仑山脉等等」。明确三项取舍：**世界高度 64 → 256 格（64 m → 256 m）**、**只改世界地形**、**新增裸岩 + 砾石**。

### 11.5.1 五阶段实施（前两阶段保证零几何变化）

| 阶段 | 内容 | 验证 |
|---|---|---|
| 1 | 列顶编码 `PackedByteArray` → `PackedInt32Array`（哨兵 255/254 → −1/−2）。**高度 256 后合法列顶可达 255，与旧哨兵直接冲突**，不改编码山体整列会被当成空列跳过 | `chunk_mesh_baseline` 60 行几何输出逐值一致 |
| 2 | `CHUNK_SIZE.y`/`SIZE.y` 64→256；`_field_column_ok` 扫描起点 `SEA_LEVEL+8` → `CHUNK_SIZE.y-1`；`_generate_chunk` 按列只写"最高可能非空气格" | 几何基线仍逐值一致 |
| 3 | 新方块 ROCK(35)/GRAVEL(36)：enum + `NAMES` + `SOLID`/`TRANSPARENT` + `TILES`(瓦片 35/36) + `HARDNESS`(3.5/0.6) + `EFFECTIVE_TOOL`(镐/锹) + 掉落映射（→圆石/→沙） | `terrain_block_probe` 22 PASS |
| 4 | 三层噪声 + 河床下切 + 材质分档 + 树线 | `terrain_survey_probe` 全 PASS |
| 5 | 平整保护区（`flat_zones` 四矩形，随 `set_region` 清缓存） | 保护区内山/河零越界 |

### 11.5.2 三层地貌（`world.gd`）

| 层 | 噪声实例 | 关键常量 | 效果 |
|---|---|---|---|
| 青藏高原地基 | `_plateau_noise`（seed+101，freq 0.0022） | `PLATEAU_H=70`，`smoothstep(0.10,0.95)` | 成片抬升的台地（海拔可达约 70 m，PLATEAU_H=70 格上限）。门限须覆盖 simplex 实际输出域 ±0.35，取 0.05/0.40 会让 `pn` 一过 0.2 整片饱和成断崖 |
| 喜马拉雅 / 昆仑山脊 | `_ridge_noise`（seed+202，freq 0.0075） | `RIDGE_H=100`、`RIDGE_SHARP=3` | `1-|n|` 的 ridged 形态收尖；乘**高原门限** `smoothstep(0.10,0.95)`，故雪山只长在高原上，不在平原凭空冒 |
| 长江 / 黄河 | `_river_noise`（seed+303，freq 0.004，1 octave） | `RIVER_CUT=15`、各向异性 x×0.4 / z×1.5 | 输入各向异性使等值线沿东西向延伸 → 自西向东的河道；下切量按 `(1−高原归一化)` 递减：平原段切到海面以下（有水大河），高原段只切宽谷 |

三个噪声 **seed 错开（+101/+202/+303）**：同源会让山脊永远长在河谷正上方，形成假关联。

### 11.5.2b 可飞性保障：保护区渐变带 + 限坡（**必读**）

分层初版出过「空气墙」事故：山脊（196 格）与平原（30 格）**直接相邻**，单步落差 **164 格（164 m）**，玩家在机场外被一堵看不见的墙拦住，飞机巡航撞上直接解体。根子不在噪声参数，而在**平整保护区的硬边界**（`if in_rect: return base_h` 一刀否决所有起伏）。

两道保险：

- **`_flat_weight(wx, wz)` + `FLAT_FEATHER = 30`**（30 m）：保护区从硬否决改为权重函数，区内权重 0、边缘渐变带线性升到 1。
- **`_limit_slope(wx, wz, h)` + `MAX_SLOPE = 6`**（6 m/格）、`SLOPE_RELAX_ROUNDS = 4`、`SLOPE_SLACK = 3`：对最终高度做邻域坡度松弛（只钳制结果，不改噪声）。松弛不反向传播，末轮常残留 1~3 格，故断言阈值写 `MAX_SLOPE + SLOPE_SLACK`。

结果：全域最大单步落差 **164 格 → 9 格（9 m）**。`terrain_survey_probe` 的 **③b「全域无空气墙」**已把它钉成回归闸——地形再改陡了立刻 FAIL。

### 11.5.3 地表材质分档（`World._surface_ids`）

区块生成（`_generate_chunk`）与战术地图估算（`_estimate_block`）**共用同一函数**，保证"地图上看到的颜色"与"世界里踩到的方块"永远同源。

| 条件 | 表层 / 地下三格 |
|---|---|
| 河心（river > 0.78） | 砾石 / 砾石 |
| 河岸（river > 0.34） | 草 / 泥土 |
| 高度 > 150（`SNOW_LINE`） | 雪 / 雪 |
| 高度 > 100（`ROCK_LINE`） | 裸岩 / 裸岩 |
| 其余 | 按区域 profile（草 / 沙） |

**树线** `tree_line=118`：高于此不长树，且河心不长树（8 格树干 + 树冠会戳到盘外，山脊可到 188）。

### 11.5.5 对飞行玩法的影响

- **山是可飞的障碍，不是墙**：飞机无空气密度模型，靠空速爬升，188 m 雪山能飞越；撞山即坠毁（既有解体逻辑）。限坡保证山麓有缓坡盘旋爬升的空间。
- **世界天花板是真硬约束**：高度 256 m 顶面有碰撞面。探针若把飞机爬到 126 m 会撞顶解体（`cockpit_instruments_shot` 曾因此连挂 4 项）。现在该探针用 `_survey_cruise_alt()` 沿航线实测地形峰值 + 余量，**并夹在天花板之下 15 m**，地形再变也不用改探针。
- **进近不受影响**：机场在保护区内且带渐变带，进场航径下的地形与旧版基本一致。
- **战术地图同步换装**：`_estimate_block` 补了分层判据 + 自带一份同参数同 seed 的 `_river_noise`（不能依赖 World 实例状态，地图要估算未加载区块），并加了裸岩/砾石配色。**这是本次唯一触碰的 UI 文件**——不改就会出现"地图把雪山画成草地"。
- **海拔表量程**：`ALT_MAX=1000 m`，188 m 雪山远未触顶。

### 8.5b 接地质量评分（U-7，D-061）

原来只有 LANDING 任务在跑时才算「过/不过」，自由飞落地没有任何反馈。现在**每一次落地停稳**都评价：

- 纯逻辑 `scripts/flight/landing_quality.gd`（`LandingQuality`）：三项连续打分，总分 0~100——
  - 触地垂直速度 40 分：|vs| 0 → 满分，≥3 m/s（任务硬着陆阈值）→ 0
  - 落点偏差 30 分：0 → 满分，≥50 m（降落区半径）→ 0；**无参照（自由飞）中性 18 分**，不奖不罚
  - 停稳滑跑速度 30 分：0 → 满分，≥25 km/h（任务停稳阈值）→ 0
- 分级文案：≥90 🏆完美降落！/ ≥75 🌟飞得很漂亮 / ≥55 👍降落不错 / ≥35 😅勉强站稳 / 其余 💥摔得有点疼
- 触发链路：触地边沿（`_physics_process` 抹零前先存真实 vs）→ 滑跑累计 → 停稳（≤1.5 m/s）或 15 s 超时 → `Events.aircraft_landed(result)` → Toast「🛬 落地 88 分：🌟飞得很漂亮」。`place()` 作废未结算 pending；坠毁不解体不算降落
- LANDING 任务 score 同步改 0~100 连续口径（原「120 − |vs|×10 − elapsed」0~200），result 增带 `landing_quality` 明细；失败仍 0 分、防刷 repeat 不变

### 10b 进近高度呼号（U-10，D-061）

- `FlightInstruments.ALTO_CALLOUTS = [30, 20, 10, 5]` 米：已离地 + 明确下沉（vs<−0.5）时 AGL 从上往下穿层即呼，同层一次飞行只呼一次；着地重置
- **独立通道**：`take_altitude_callouts()` 与 `take_voice_cues()` 平行，刻意不并 alerts() 的「同刻只播最高级」——降落末段被失速/超速警告挤掉就失去存在意义（警告防事故，呼号教节奏）
- HUD tick 消费：蜂鸣 `alt_call`（780 Hz 两声）+ Toast「📢 N 米」；档位不照搬 IF 英尺（本世界跑道 336 m）
- `tests/landing_quality_probe`（45 断言：纯逻辑边界 / 任务改造 / 呼号边沿 / 端到端真实飞机落地）

另有两条 D-054 留给你定的点：

1. **首次出现的教学提示**："把准星套进十字"这句还没做（现在靠动作词标签自解释，没接教练系统）
2. **巡航时指引十字的存在感**：目标固定为机场，飞离后十字会长期贴在边缘呈红色（提示掉头回去）。这是"导航目标 = 机场"的语义正确结果，若嫌吵可让它在 >800 m 时淡出或降为琥珀 —— **D-090 已落地「>800 m 淡出」**：`flight_director.gd` 新增 `CRUISE_FADE_DIST=800.0`，仅降 `col.a`（下限 0.3，4000 m 线性衰减到 0.3），**不改模式 / 几何 / 文案**，与既有 `OFF`/`visible` 逻辑与探针断言（`label_text()`/`_color_for()`）零冲突。

对比依据与优先级判定见 **§16.5**。

### 10c 失速提示的三层通道与改出教案（U-6 / U-8，D-069）

**先说去重（U-6）**：失速原本在三处报——飞行卡片失速行、仪表 HUD 全宽警告横幅、蜂鸣。三者同刻齐发既吵又互相压字。D-069 的分工是：

| 层 | 内容 | 归属 |
|---|---|---|
| 告警层（非文字） | 蜂鸣（880 Hz 急鸣 / 交替连续）+ SPD 盘红闪 + 空速行变红 | 既有，零新增；**不计入去重**（声音与颜色不占文字位） |
| 文字层（权威） | 失速改出教案 ①/②/③/成功 | `StallCoach`，占用飞行卡片的教练区四节点 |
| 让位层 | `FlightInstruments.banner_alerts()` = `alerts()` 剔除 `stall` / `stall_full` | 全宽横幅只报**非失速**警告 |

卡片失速行随之删除，D-046「失速行永远可见」的职责移交给教练区——失速教案①起教练区非空，卡片在座舱视角下自然保持可见。

**再说教案（U-8）**：`scripts/ui/stall_coach.gd`，与 `TakeoffCoach` 同范式（纯逻辑器，不绘制界面，输入 `Aircraft.snapshot()`，输出 `{text, sub, color, flash, bar}`）。

```
IDLE ──(stalled ∨ stall_warning 上升沿，且 AGL>2 m)──▶ ① 松杆低头
 ① ──(俯角 ≤ −3° 维持 0.3 s)──▶ ② 油门推满 ──(余量 ≥0 维持 0.3 s)──▶ ③ 等速度恢复
 ③ ──(余量 ≥10 km/h)──▶ 成功（保持 2.5 s）──▶ IDLE
任意态 ──(再次完全失速上升沿)──▶ ① ；②③ 单步 15 s 无推进 ──▶ IDLE ；AGL ≤2 m ──▶ IDLE
```

| 设计点 | 取值 | 理由 |
|---|---|---|
| 触发 | `stalled ∨ stall_warning` 上升沿（一扇门两把钥匙） | 儿童向：**接近**失速就开始教，不等真失速；不设第三种入口、不加会话计数器 |
| ①文案 | stalled → 红闪「失速了！按【↓】低头」；仅 warning → 黄闪「要失速了，按【↓】低头」 | 同一动作两种语气，不把警告夸大成事故（与 `FlightInstruments.alerts()` 文案严格一致，D-090 订正：原「推杆低头」对键盘儿童不直观，且与原 `StallCoach` 提示「按【↓】低头」不一致） |
| ① 超时 | **不设**（着地才收） | 指令性步骤，防儿童慌乱期提示中途消失 |
| ②③ 超时 | 15 s 无推进 → IDLE 静默 | 危险已过就停止跟读 |
| ② 完成判据 | 失速余量 ≥0（不是油门门控） | **教学提示与完成判据分离**：②只「教」加油门，不「考」它——俯冲改出但没推油门的儿童不该被卡住 |
| ③ 完成判据 | 余量 ≥10 km/h（≈2.8 m/s） | 温和，不易二次失速 |
| 熄火交圈 | ② 遇 `engine=false` 改教「先按【F】点火」 | 与起飞教练的「按 F」分支同文案形状，点火后自动回到推油门措辞 |
| 主句字号 | 失速教案 **17 / 副句 13**；起飞教练维持 15 / 12 | U-6 后失速文字通道只剩教练区一份，15px 在座舱里显著度比旧全宽 22px 横幅降明显；起飞教练内容非安全关键，且卡片行高按 15 排过版，不动 |

**两块教练区的同屏互斥**：起飞教练 `_step_of()` 顶部 `if stalled or stall_warning: return {}`，失速教案全权负责；hud.gd **每帧各调一次**两个 coach（不能只调占位的那个——起飞教练的内部计时必须照常推进，否则失速教案结束后它从冻结时刻续跑，「🎉 起飞成功」会在教案收尾后复活）。

## 16. 横向对比：与同类飞行游戏的差异

### 16.1 参照物与口径

| 参照 | 为什么选它 | 主要借鉴 |
|---|---|---|
| **War Thunder（战雷）** | 座舱仪表风格的**直接参考**（用户点名"参考战雷老式战机仪表"）；且它的 AB/RB/SB 三模式本身就是一套"辅助多少"的对照实验 | 仪表观感；SB 模式"禁用 HUD、必须自己读表"的体验目标 |
| **MSFS（微软飞行模拟）** | 引导 / 训练 / 评分的**上限参考** | 接地三项评分、训练关卡结构、副驾代执行 |
| **Infinite Flight** | **移动端**飞行模拟的成熟形态（本作要上中低端 Android） | HUD 飞行指引十字、ILS/APPR、进近高度呼号 |
| **SimplePlanes** | 与"零件建造 + 真气动"**最近的同类** | 重心 / 升力中心可视化、试飞迭代闭环 |
| **Ace Combat（皇牌空战）** | 街机向的**另一端**——用来确认"我们不做什么" | 反面对照 |
| **Minecraft 鞘翅** | **体素品类的飞行基线**——本作要超越的对象 | 反面对照 |

> **口径**：对比以各作主流公开版本的常见形态为准 —— 战雷取 RB / SB（AB 有 Instructor 与提前量辅助，不代表其气动上限）、MSFS 取 2020/2024 通用体验、Infinite Flight 取现行移动端版本、SimplePlanes 取 1/2 代、Minecraft 取 Java 版鞘翅。**不追求逐版本精确**：对比的目的是定位与找差距，不是考据。

### 16.2 定位坐标系

同类飞行游戏里，**气动真实度与上手门槛通常是正相关的**（越真实越难）。本作刻意打破这个相关性：

```text
  上手门槛
   ▲ 高 │   DCS●            X-Plane●
        │                     MSFS●
        │              战雷SB●
        │        SimplePlanes●
        │     战雷RB●   InfiniteFlight●
        │
        │   AceCombat●              ★ 本作
        │   Minecraft鞘翅●
        └──────────────────────────────────▶ 气动真实度
          低                                高
```

> DCS / X-Plane 只在坐标系里标出"硬核端"的位置，不参与 §16.3 的逐维度对比 —— 它们与本作的目标用户没有交集。

**本作落在右下角的空档象限**：气动是真的（升力线 + 失速 + 诱导阻力 + 密度衰减 + 动压权限，见 §4.2），但门槛刻意压低（教练四步 + FD 十字 + 辅助三档 + 宽容惩罚）。同类里几乎只有它在"中高真实度 / 低门槛"这一格。

一句话概括与战雷的关系：**本作 ≈ 战雷 RB 的气动 + 战雷 SB 的座舱视角 + 战雷 AB 的辅助强度，再整体下调到儿童可上手。**

### 16.4 逐竞品：学什么 / 不学什么

#### ① 战雷 —— 学仪表观感与"SB 体验目标"，不学它的门槛

- **学**：黑盘面 + 白硬边刻度 + 琥珀指针 + 金属板（D-052 已落地）。战雷 SB"禁用 HUD、必须自己读表"这个体验目标，正是本作 2D 座舱簇存在的理由 —— **本作等于把 SB 的体验做进了默认视角**。
- **不学**：Instructor 的二值开关（AB/RB 有、SB 无）。本作做成**三档可调且松杆才接管**（三轴杆量 <0.05 才生效，一压杆立刻让位），比二值更尊重玩家输入。
- **差距（已缩小）**：战雷座舱是真 3D，环顾/低头有物；本作原是纯画的（**U-1 / U-2**），**D-065 已补 3D 内装层**，差距大幅收窄——仅蓝图试飞机仍按契约不建几何。

#### ② MSFS —— 学评分与训练结构，不学它的深度

- **学**：**Landing Challenge 三项评分** —— 接地精度（接地点相对目标区）/ 接地平顺度（触地下降率）/ 滑跑控制（方向与偏移）→ 直接对应 **U-7**；"虚拟教官全程课程 + 专用着陆课"→ 对应 **U-8**。
- **不学**：完整 ATC / 检查单 / 航路规划。儿童向不需要，且本作单局只有几分钟。
- **已对标**：MSFS 的 Landing Path / 天空航点标记 → 本作已有 3D 下滑道双轨 + 地面箭头（§9.2）。

#### ③ Infinite Flight —— 学指引十字的语义与进近反馈，不学自动驾驶

- **学**：**HUD 飞行指引十字（pink crosshairs）** —— 与 D-054 的 command bars 语义完全一致，**反向验证了 D-054 的选择是对的**（偏移式指令杆，而非单纯的偏差条）；**50/40/30/20 高度呼号**给进近末段一个节奏锚点。
- **不学**：APPR 自动落地、LNAV/VNAV 全自动航路。本作刻意"只给指令不代飞" —— 飞行本身是玩法，交给自动驾驶等于把玩法删掉。
- **差距**：缺高度呼号与接地评分 → **U-7 的一部分 + 新增 U-10**。

#### ④ SimplePlanes —— 学重心可视化，不学它的自由度

- **学**：**CoM / CoL / CoT 三色指示器**。本作零件聚合**已经在算**重心（质量加权）与升力中心（面积加权），见 §4.4 —— **数据都在，只差画出来**。对儿童尤其友好：能直观看到"为什么我一松杆就栽头"。
- **不学**：无限几何自由度 + XML 改参数 + 零件过载脱落。本作是 9 种零件的体素装配，**自由度过低不是缺陷而是定位**（可控、可预期、默认套件手感恒定）。
- **差距**：蓝图界面缺重心/升力中心可视化 → **新增 U-11**。

#### ⑤ Ace Combat / Minecraft 鞘翅 —— 反面对照（确认我们不做什么）

- **Ace Combat**：街机向，气动高度简化、无失速建模。**不做** —— 本作的核心卖点之一就是"气动是真的"，失速是真的会掉下来。
- **Minecraft 鞘翅**：纯滑翔，无升力/失速模型，靠俯仰换速度；创造模式更是完全无视物理。**这是体素品类的飞行基线**，本作的目标就是明显越过这条线：把"能飞"升级为"要会飞"。

### 16.6 本作已有的差异化（同类没有的组合）

1. **体素沙盒里的真气动** —— 同类体素游戏（含鞘翅）基本没有升力/失速模型；有真气动的（MSFS / SimplePlanes）又不是体素沙盒。
2. **真气动 + 低门槛** —— 通常这两者正相关。本作用"教练四步 + FD 十字 + 辅助三档 + 宽容惩罚"把门槛压下来，落在同类坐标系的**空档象限**（§16.2）。
3. **座舱 2D 化 + D-065 3D 内装层** —— 用纯 2D 覆盖层做到"仪表可信 + 成本极低"，并由 D-065 补 3D 内装层（环顾视差 / 低头可见仪表台）缓解原 U-1 结构性缺陷；对中低端 Android 是划算的取舍（无需额外的座舱几何与贴图预算）。
4. **飞行是世界里的一种活动，不是独立关卡** —— 机场落在真实地形上、昼夜天气影响能见度、零件用绿宝石解锁、成就与回放接入统一系统。同类飞行游戏的飞行通常是独立关卡/独立菜单。
5. **单一数据链路** —— `AircraftFlight → FlightInstruments →` 座舱 2D / 追尾四角 / 3D 面板 / 战术地图 / FD 十字共用一份读数，多视图永远一致，不是各画各的。
