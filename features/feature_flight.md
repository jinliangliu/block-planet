## 1. 概述

玩家在世界里放置/拼装一架轻型单发固定翼飞机，登机后进入**第一人称座舱**，用鼠标（或触屏摇杆）当操纵杆、键盘推油门，完成起飞 → 巡航 → 进近 → 降落。座舱内所有仪表与内装是**一块屏幕最上层的 2D 像素绘制**（不用 3D / ViewportTexture），风格参考战雷（War Thunder）老式战机仪表：黑盘面 + 白色硬边刻度 + 琥珀指针 + 金属仪表板。

一句话概括现状：**气动是真的（简化真实气动模型），座舱是画的（纯 2D 覆盖层）**。

关键设计取向：

| 取向 | 落地方式 |
|---|---|
| 儿童友好 | 辅助稳定三档（默认"标准"=半开）、失速留 35% 残余升力、警告带蜂鸣码与动作词、起飞教练四步阶梯 |
| 看得懂打得准 | 气动只保留核心：升力随攻角线性→失速掉落、诱导阻力随 CL²、密度随高度衰减、操纵权限随动压下降 |
| 数据单一来源 | `AircraftFlight`（气动）→ `FlightInstruments`（仪表加工）→ 座舱 2D / 追尾四角 / 3D 面板 / 战术地图共用同一份读数 |
| 座舱可信 | 2D 像素内装（风挡支柱 / 侧 console / 磨损 / 螺钉）+ 战雷式圆盘仪表 + 飞行指引十字 |
| 移动端可达 | 触屏飞行层（左下摇杆 + 右下油门 + 方向舵/刹车 + 右上按钮排） |

## 2. 玩家流程

```text
进图（探索模式赠机 / 机场跑道待发）
→ 走近飞机按 F 登机
→ 【自动】相机复位到第一人称座舱（D-049），满油、襟翼回 0 档
→ 起飞教练接管：① 按 F 点火 → ② 按 W 推满油门 → ③ 滑跑到抬轮速度 → ④ 按 ↑ 抬轮
→ 离地爬升（飞行指引十字给 8° 爬升指令）
→ 巡航（十字只导航向；M 键战术地图看位置）
→ 接近机场（≤400 m 转进近，十字给 3° 下滑道指令，世界里有地面箭头 + 下滑道双轨）
→ 接地滑跑（空格刹车）
→ X 下机（自动熄火、油门锁 0）
→ 坠机时：按 Y 一键回到本图初始跑道（玩家 + 飞机归位、满油待发）
```

## 4. 飞行物理与气动

### 4.1 世界尺度与整机尺寸

| 项 | 值 | 出处 |
|---|---|---|
| 1 格 | 0.5 m | D-030 |
| 机身长 / 翼展 | 10.2 m（约 20 格）/ 24 m（48 格） | `aircraft.gd` 头注释 |
| 碰撞盒 | 6.6 × 4.8 × 15.6 m（13.2 × 9.6 × 31.2 格） | `COLLIDER_SIZE` |
| 机轮离地净空 | `AircraftModel.GROUND_CLEARANCE` | 与机模共用 |
| 座位偏移（脚底） | `(0, 1.35, -2.8)` | `SEAT_OFFSET` |
| 座舱眼位 | `(0, 1.15, -3.4)` | `AircraftCamera.COCKPIT_OFFSET` |

⚠️ 碰撞盒只包机身，**翼展 24 m 不参与碰撞**（否则一路刮蹭树冠屋檐）。且碰撞盒**恒定世界水平**（`_pin_collider`），不随机体姿态转——这是 D-048 的结论：随机体转会把机尾/翼尖埋进地面，起降全都变成坠毁。姿态旋转只作用于外观与读 `global_transform` 的下游（相机 / 仪表 / 座位 / 录制 / 流式窗口）。

### 4.2 气动常量（`aircraft_flight.gd`）

| 常量 | 值 | 含义 |
|---|---|---|
| `GRAVITY` | 9.80665 | |
| `SEA_LEVEL_DENSITY` | 1.225 kg/m³ | |
| `DENSITY_SCALE_HEIGHT` | 8500 m | 密度指数衰减标高（8500 m 处约 37%） |
| `CL_ALPHA` | 5.0 /rad | 升力线斜率（3D 机翼实测低于 2π） |
| `CL_MAX` | 1.6 | 升力系数上限 |
| `STALL_ALPHA` | 0.32 rad ≈ 18° | 临界攻角（= CLmax / CLα，自洽） |
| `STALL_WARN_ALPHA` | 0.27 rad | 失速预警 |
| `CD0_BASE` | 0.06 | 零升阻力基值 |
| `INDUCED_K` | 0.052 | 诱导阻力因子 |
| `SIDESLIP_DRAG` | 0.35 /rad | 侧滑附加阻力 |
| `THRUST_DENSITY_EXPONENT` | 0.7 | 螺旋桨推力随密度衰减指数 |
| `VNE` | 55.0 m/s（198 km/h） | 结构极限速度，超出即解体 |
| `FLAP_VFE` | 30.0 m/s | 襟翼标速（超速放襟翼只提示不硬拦） |
| `ROLL_RATE_MAX` / `PITCH_RATE_MAX` / `YAW_RATE_MAX` | 2.2 / 1.1 / 0.55 rad/s | 三轴最大角速度 |
| `RATE_RESPONSE` | 4.5 /s | 舵面响应时间常数倒数 |
| `CONTROL_Q_REF` | 250 Pa | 操纵权限基准动压 |
| `CONTROL_AUTHORITY_MIN` | 0.12 | 低速杆效下限（杆变软但不失效） |
| `YAW_STABILITY` | 1.1 | 风标稳定性（机头自动朝向来流） |
| `TURN_COORDINATION_RATE` | 0.5 | 坡度自然带出偏航（不踩舵也能协调转弯） |
| `PITCH_LIMIT` | 1.45 rad ≈ 83° | 空中的俯仰限位 |
| `GROUND_PITCH_MAX` | 0.21 rad ≈ 12° | **地面**机轮限位（可抬头离地，不能翻跟头） |
| `CRASH_IMPACT_DV` | 7.0 m/s | 单帧速度损失超此值即解体 |

**"压坡度就会转弯"没有额外公式** —— 升力方向取 `basis.y` 去掉速度分量，滚转时升力自然被掰向侧向，转弯是升力侧向分量的结果。

**失速后保留 35% 残余升力**（`lift_coefficient`）：避免"一失速就直接坠地"，给儿童留出改出余地。

### 4.4 零件聚合（`Airframe.aggregate`）

整机不再是"烘焙好常数的飞机"，而是**由零件拼装、物理按零件求和**：

- 随零件变化：总质量、翼面积、推力、零升阻力、燃油容量、油耗、重心（质量加权）、升力中心（面积加权）
- 结构限速 VNE = 所有零件 `vne_limit` 的**下限**
- 跨零件共享（保持静态）：翼型曲线、大气、操纵品质

零件表（`part_registry.gd`）：

| 零件 | 质量 kg | 推力 N | 升力面积 m² | 燃油 L | 油耗 L/s | 成本 |
|---|---|---|---|---|---|---|
| 机身 fuselage | 119 | — | — | — | — | 0 |
| 机翼 wing | 30 | — | 12 | — | — | 5 |
| 尾翼 tail | 8 | — | 2 | — | — | 3 |
| 发动机 engine | 45 | 1650 | — | — | 0.10 | 12 |
| 螺旋桨 propeller | 6 | — | — | — | — | 4 |
| 起落架 gear | 12 | — | — | — | — | 3 |
| 油箱 fuel_tank | 20 | — | — | 55 | — | 4 |
| 涡轮发动机 turbine | 55 | 1750 | — | — | 0.18 | 30（绿宝石解锁） |
| 长航程机翼 long_wing | 42 | — | 18 | — | — | 20 |

默认套件的聚合结果与旧标定逐项一致，所以**换零件不改变默认手感**，只改变"造得大飞得远"这类可预期的量（2 油箱 = 110 L）。

### 4.5 燃油 / 发动机 / 襟翼

| 项 | 值 |
|---|---|
| 燃油容量 | 聚合值（默认 55 L）；**出生 / 装配 / 每次登机都补满**——油是"这一程"的资源，不是耐久 |
| 油耗 | `fuel_burn × 油门`（默认 0.10 L/s），怠速不耗，熄火不耗 |
| 续航 | 满油满油门 9.2 min；半油门巡航 18.3 min |
| 耗尽 | 自动熄火（油门锁 0、无推力），**舵面仍可滑翔降落**——不坠毁不爆炸 |
| 低油警告 | ≤20% 触发，>25% 才清除（滞环防边界抖闪） |
| RPM | `600 怠速 + 2100 × 平滑油门` = 0..2700；τ = 0.4 s；熄火后自旋减速到 0 |
| 襟翼 | 3 档（0 洁净 / 1 起飞 / 2 着陆），Z 键循环；CL 倍率 1.0 / 1.25 / 1.5，CD 加数 0 / 0.010 / 0.022 |
| 起落架 | 固定式，恒放下锁定（绿色灯） |

### 4.6 辅助稳定（`FlightSettings`）

三档，默认**标准 = 半开**：

| 档 | roll_level | yaw_damp |
|---|---|---|
| 关闭（硬核） | 0.0 | 0.0 |
| 半开（标准） | 0.9 | 0.8 |
| 全开（休闲） | 1.8 | 1.5 |

规则：
- **只在松杆时接管**（三轴杆量 <0.05 才生效）；玩家一压杆，辅助立刻完全让位。
- 只做**坡度摆平 + 偏航阻尼**。**刻意不做俯仰自动配平**——那会与爬升/失速这类正常俯仰机动对抗，也会搅乱"满拉杆逼失速"的主动改出。
- 另有**自动改平**（双击左键，2 s 内以增强增益把坡度与俯仰一并摆平），与松杆配平刻意区分：它含俯仰，且增益取 `max(辅助档, 0.9)×2.5`，硬核档下也能生效。

### 4.7 地面物理

- 轮胎抓地：水平速度被拽向机头方向（`GROUND_GRIP = 3.0 /s`）
- 滚动阻力 0.6 m/s²；刹车 6.0 m/s²
- 前轮转向 `STEER_RATE = 0.8 rad/s`，**按速度衰减**（高速靠气动舵面）
- ⚠️ 地面时气动层**不叠**杆量偏航：真实飞机地面滑跑方向舵无气动效用，转向靠前轮（修复前实测 ≈77°/s，轻点方向舵就冲出跑道）

## 6. 视角系统（`AircraftCamera`）

六种模式，后视 / 自由观察 / 地图 / 回放都是**覆盖层**，退出时回到底层模式（`_base_mode`，只有座舱 / 追尾两种）。

| 模式 | 参数 |
|---|---|
| FIRST_PERSON | 眼位 `(0, 1.15, -3.4)`，视线在机头上仰基础上再抬 1.1 m @10 m 前视 |
| CHASE | 距离 13 m（滚轮 8..20）、高 4.5 m、前视 lead 2 m |
| REAR | 距离 7 m、高 2.6 m，回头拍机体 |
| FREE_LOOK | 座舱内环顾 / 追尾球面环顾；灵敏度 0.0025 rad/px，俯仰限 ±1.1 rad |
| MAP | 高 60 m（20..120），north-up |
| REPLAY | 位姿由 `FlightReplay` 直写 |

通用：

- **阻尼**：远距 4.0 /s（τ≈0.25 s，模式切换柔和）、近距 25.0 /s（τ≈0.04 s，55 m/s 全速只拖影约 2 m）；指数阻尼永不过冲
- **FOV**：飞行 82°（战术地图 70°）。75°→82° 是"视场不够宽"的定量化落地：座舱里被仪表板与舱框一挡，窄视场只剩一条缝
- **追尾 / 后视抑制滚转**（地平线稳定，防晕）
- **防穿模**：10 Hz 射线，命中则拉近到命中点前 0.5 m
- **镜头抖动**：幅度 0.05 m，按油门/空速缩放，可在设置里关
- **登机默认第一人称**（`reset_to_cockpit`，同时写 `_mode` 与 `_base_mode`——只写 `_mode` 会被覆盖层退出掀回追尾）

## 7. 座舱设计（重点）

### 7.1 结构性结论：座舱是"画的"，不是"建的"

`Aircraft` **没有座舱内装几何**。第一人称的实现是三步：

1. **隐藏整机外观**（`set_cockpit_interior(true)`）——因为眼位 `(0, 1.15, -3.4)` 落在机身盒内部，而机翼（y 1.335..1.785）正压在视平线上。不隐藏的话，"第一人称"看到的先是自己的机翼再是世界（用户实测截图：机翼横贯全屏）。
2. **相机放进机身内**（见 §6）。
3. **一块全屏 2D `Control` 画整个座舱**（`CockpitInstruments`）——框体、仪表板、六件仪表、磨损，全部是 `draw_rect` / `draw_colored_polygon` / `draw_circle(antialias=false)` 拼出来的硬边像素。

由此推出的必然结果（不是 bug）：**环顾时框不动**（2D 层不参与 3D 相机）、**低头看不到仪表台**（没有 3D 内装）。这两条是审核报告 U-1 的结构性项，待定路线（补 3D 内装 / 锁死环顾 / 维持现状）。

`CockpitPanel`（3D 仪表板，SubViewport → ViewportTexture）是**另一条独立路径**：它挂在机体上、低头可见，但第一人称下也被隐藏（读数已由 2D 簇接管），只在追尾/环顾时随 3D 视野出现。蓝图试飞机无座舱罩，按契约不建几何。

### 7.3 仪表板尺寸与自适应

```gdscript
const REF_VP     := Vector2(1280.0, 720.0)   # 基准视口
const SCALE_MIN  := 0.70                     # 太小刻度糊成一片
const SCALE_MAX  := 2.80                     # 太大面板压掉视野

static func ui_scale(vp) -> float:
    return clampf(minf(vp.x / 1280.0, vp.y / 720.0), 0.70, 2.80)
```

**为什么要自适应**（这是 D-052 的核心修复，也是"尺寸不合理"的真实根因）：
项目用 `stretch=canvas_items + aspect=expand`，逻辑视口**宽恒 1280、高度随宽高比在 590~720 之间漂移**（19.5:9 手机实测 1280×590）。固定像素下仪表占屏高会从 21% 漂到 26%。改为"基准视口 + 等比缩放 s"后，任何宽高比都锁在同一比例（实测离散度 **0.0000**）。

⚠️ 一个已纠正的误判：`--resolution 1920x1080` 实测传给脚本的仍是 1280×720，`canvas_items` 下逻辑视口恒定。**真实漂移来自 `aspect=expand` 的高度，不是分辨率**。

布局基准（s=1，全部自屏幕底边起算）：

| 常量 | 值 | 说明 |
|---|---|---|
| `MARGIN_B` | 12 | 簇底距屏幕底 |
| `GAUGE_SZ` | 152 | 地平仪外径（最主仪表，居中） |
| `SIDE_SZ` | 140 | 空速/高度盘外径 |
| `BEZEL` | 9 | 金属压环总厚（含 3px 受光边） |
| `GAUGE_GAP` | 20 | 盘间距 |
| `TAPE_W` / `TAPE_H` / `TAPE_STRIP` | 600 / 56 / 34 | 航向带（3 上条 + 34 刻度窗 + 数字窗） |
| `TAPE_PPX` | 5.0 | 像素/度（600 px ≈ ±60° 视野） |
| `DASH_PAD` / `DASH_LIP` | 18 / 4 | 底板左右 padding / 顶沿受光条 |
| `BAR_W` | 32 | 油门/燃油竖条宽 |
| **`GAUGE_K`** | **2/3** | **盘排竖向压缩比（D-053，用户圈注"高度缩小 1/3"）** |
| `PITCH_MAX` | 60° | 俯仰钳制（超过截断、不无限滚动） |
| `SPD_MAX` / `ALT_MAX` | 250 / 1000 | 盘量程 |
| `BLINK_MS` | 600 | 闪烁周期（与警告横幅一致） |

⚠️ `GAUGE_K` **只压盘排本身**（表盘直径、盘间距、簇底留白、竖条宽），航向带与底板宽度不动——宽度由 `TAPE_W` 决定，用户只要求高度。

**盘内细节按"盘径 / 设计稿尺寸"取尺**（不乘 `ui_scale`）：
```gdscript
var s := sz / GAUGE_SZ     # _AttitudeGauge / _RoundGauge 的 _draw() 开头
```
否则盘缩到 2/3 而字号、压环、指针原地不动，会糊出盘外。

s=1（1280×720）实测几何：

| 件 | 矩形 |
|---|---|
| 主表（地平仪） | x 589.3, y 610.7, 101.3×101.3 |
| SPD | x 482.7, y 614.7, 93.3×93.3 |
| ALT | x 704.0, y 614.7, 93.3×93.3 |
| 航向带 | x 340.0, y 546.7, 600×56 |
| THR / FUEL | x 338.0 / 920.7, y 614.7, 21.3×93.3 |
| dash 底板 | x 322.0, y 538.7, 636×181.3 |

比例：**dash 占屏高 25.2%**（压缩前 32.8%）、**主表占屏高 14.1%**（压缩前 21.1%）。

### 7.4 六件仪表（逐一）

#### ① 地平仪（主表，居中，最大）

- **圆盘**：三层金属压环（受光边 → 暗部 → 盘面）+ 45° 玻璃反光（alpha 0.035）
- **天地**：「圆 ∩ 地平线半平面」裁剪填充（`clip_seg_circle` + `clip_poly_half` + `circle_poly`），天地在圆内截断
- **俯仰** → 天地垂直偏移；**横滚** → 整个天地旋转；**±60° 钳制**，超过画面截断不无限滚动
- **俯仰阶梯** `LADDER = [10°, 20°, 30°]`：只画盘缘两侧（不横贯盘面抢读数），用 `clip_seg_circle` 裁进圆
- **横滚刻度** `ROLL_TICKS = [0, 10, 20, 30, 45, 60]`：沿盘内缘
- **飞机标记**：琥珀色、固定不随姿态动（这是"飞机符号"，天地动、飞机不动）
- 数字锚点贴在阶梯线内侧（`lseg[1].lerp(lseg[0], 0.14)`）

#### ② 空速（SPD，主表左侧）

- 270° 环形刻度（25 格）+ 琥珀指针 + 中心轴
- 量程 0..250 km/h；超量程指针停满偏，数字窗永远显示真实值
- **盘下数字窗**（0.62 宽 / 0.28 高）：数字左、单位右，同一行（放到盘外会飘到板上像无主文字）
- 超速 / 失速 / 接近失速 → 告警配色
- 标签移为"窗标题"（数字窗上方 3px），不与指针重叠

#### ③ 高度（ALT，主表右侧）

- 与空速同款，量程 0..1000 m（儿童向飞行几乎全在 300 m 以下，取 2000 会让指针长期贴着最低刻度不动）
- **高度过低（`alt_warn > 0`）→ 数字变红并按 600 ms 闪烁**

#### ④ 航向带（压在盘排上方）

- 上下金属条 + 内窗 + **两端六级渐隐**（连续不跳变）+ 琥珀指针（竖线 + 倒三角）+ 带下数字牌
- 左右固定基准小三角
- 359°→0° 取模连续
- 5 px/度，600 px ≈ ±60° 视野

#### ⑤ / ⑥ THR / FUEL 竖条

- 贴 dash 内沿（填掉盘排两侧空洞）
- THR = 油门指令值（0 时暗）；FUEL = 燃油比例（低油变红）
- 填充色比指针暗一档 `Color(0.86, 0.62, 0.18)`

### 7.5 飞行指引十字（Flight Director Cross，D-054）

座舱里现在有**两个十字**，不能混：

| | 外观 | 含义 | 动吗 |
|---|---|---|---|
| **准星**（D-034 既有） | 白色细十字，臂长 36，alpha 0.6 | 机头**现在**指哪 | 固定屏幕中心 |
| **飞行指引十字**（D-054） | 彩色粗十字 + 端帽 + 黑描边，臂展 70 | 机头**应该**指哪 | 随偏差偏移，限幅 ±120 px |

**操作语义 = 真实 FD command bars：把准星套进指引十字 = 沿正确航径飞。**

导引律：

| 常量 | 值 |
|---|---|
| `GAIN_PX_PER_DEG` | 11.0（偏差 1° → 偏移 11 px） |
| `MAX_OFF` | ±120 px |
| `DEV_CLAMP` | ±12°（单轴偏差角钳制） |
| `GLIDE_DEG` / `CLIMB_DEG` | 3°（进近下滑）/ 8°（起飞爬升） |
| `APPROACH_DIST` | 400 m |
| `ROLL_AGL` / `CLIMB_CEIL` / `TAKEOFF_DIST` | 2 m / 60 m / 200 m |
| `CAPTURE_DEG` / `WARN_DEG` | 1.5°（绿 + 四角括号）/ 12°（红） |
| `ARM` / `ARM_T` / `GAP` / `CAP_W` | 34 / 3 / 11 / 15 |
| `BRACKET` / `BRACKET_L` / `ARROW` | 46 / 11 / 15 |
| `LABEL_DY` | −46（标签固定挂在**上方**） |

- **水平**：目标方位 − 当前航向（复用 HSI/CDI 的 `nav_dev_deg`，正 = 目标在右 → 十字右移）
- **垂直**：相对 3° 下滑道平面的高度偏差，`gs_y = target.y + d·tan3°`，`dev = −atan2(craft.y − gs_y, d)`（高于下滑道 → 低头追回）。分母有 30 m 下限，防止贴脸时 atan2 发散。

五个模式：

| 模式 | 判据 | 引导内容 |
|---|---|---|
| OFF | 无导航目标 / 空速 <10 km/h | 不显示 |
| ROLL | AGL < 2 m | 锁起飞航向，不引导俯仰 |
| TAKEOFF | AGL <60 m 且 升降率 >1 m/s 且 距机场 <200 m | 锁航向 + 8° 爬升 |
| APPROACH | 水平距离 ≤400 m | 直飞目标 + 3° 下滑道 |
| CRUISE | >400 m | **只导航向，俯仰不干预**（避免被迫下降） |

⚠️ **TAKEOFF 必须靠"升降率 + 离地高度"判，不能靠距离**：起飞时机场就在脚下（d≈0），只按距离会立刻被判成 APPROACH 并引导下降——起飞瞬间被提示低头是最危险的错引导。

颜色三档（实测像素值）：绿 `(115,242,140)` / 琥珀 `(255,184,51)` / 红 `(242,76,66)`。
标签给**动作词**（左转 / 右转 / 掉头 / 抬头 / 低头）而非模式名——玩家看得出该往哪修。
超量程时在十字**外侧**补同向箭头（画在臂内会被自己盖住）。

目标复用既有的 `set_navigation`（HSI / CDI / 3D 标注 / 十字永远同源），`main.gd` 零改动。

## 9. 引导与教学

### 9.1 起飞教练（`TakeoffCoach`，纯逻辑）

存在的理由（两个真实卡点，都是提示缺失而非物理错误）：
1. 登机时发动机**默认熄火**，熄火时油门锁 0 → "推油门飞机不动"，玩家不知道要按 F
2. 拉杆是 ↑/↓，鼠标只在**座舱视角**才是操纵杆，而 D-049 前默认视角是追尾 → 晃鼠标毫无反应

四步阶梯（前一步没做完就不提示下一步）：

| 步 | 文案 | 说明 |
|---|---|---|
| ① | 按【F】启动发动机 | 地面/空中都要；闪烁提示 |
| ② | 按住【W】推满油门 | 或 Shift 一键推满；带进度条 |
| ③ | 继续滑跑加速 x / VR km/h | **VR = 失速速度 × 1.2**（跟着 stall_speed 走，不写死 50 km/h） |
| ④ | 轻按【↑】抬轮 | 速度够了才喊，避免早抬轮失速 |

离地 >15 m 报"🎉 起飞成功！"停留 3.5 s，之后返回空字典（HUD 收起教练区）；落回地面自动重新接管。
**失速故意不归教练管**——卡片失速行 + 全宽警告横幅都在报，教练再插一条会在顶部居中互相压字。

### 9.2 世界 3D 引导（`FlightMarkers`，仅追尾可见）

- 目标点：金色双环（贴地）+ 悬浮 `Label3D` 名称/距离（Y-billboard）
- 地面箭头：从进近起点沿跑道轴向列 6 个，间隔 40 m
- **3° 下滑道双轨**：从 250 m 外、高度 +13 m 处沿 3° 下降引向目标
- 距目标 <50 m 整体淡出（避免贴脸挡视线）

## 10. 警告系统

`FlightInstruments.alerts()` 六类，按优先级排序（同级内 WARNING 在 CAUTION 前）：

| id | 级别 | 文案 | 蜂鸣码 |
|---|---|---|---|
| stall_full | 警告 | 失速了！推杆低头 | 880/620 交替连续 |
| stall | 注意 | 要失速了，推杆低头 | 880 Hz 急鸣三声 |
| overspeed | 警告 | 飞太快！收油减速 | 660/520 双音循环 |
| fuel_empty | 警告 | 没油了！滑翔降落 | 330 Hz 长低音 |
| altitude_critical | 警告 | 快拉升！ | 700 Hz 两声 / 0.5 s |
| altitude_low | 注意 | 离地面太近！ | 700 Hz 两声 / 1 s |
| low_fuel | 注意 | 油不多了，准备降落 | 440 Hz 慢滴三连 |

规则：

- **同刻只播最高级那条的声音**，其余留灯光（防声音叠加成噪音）
- 低油滞环 20% / 25%
- 高度过低**刻意要求下沉率条件**（注意 AGL<15 且 VS<−2.5；警告 AGL<6 且 VS<−4；着地或 AGL>20 清除）——否则降落进近全程报警，儿童会学会忽略警报（警报疲劳比没警报更糟）
- 蜂鸣码全部落在 330–880 Hz、单条 ≤1.2 s，避免刺耳；`user://voice/<id>.wav` 存在时优先播采样（预留语音资产接口）
- 主音量 0.22（提示不是警报）；设置里可整体关闭

## 12. 任务 / 回放 / 成就

- **任务**（`MissionData`，K 键面板）：三种 —— TAKEOFF（目标离地 30 m、最低安全空速 40 km/h）/ CIRCUIT（绕点，判定半径 30 m）/ LANDING（降落区半径 50 m、触地垂直速度 ≤3 m/s、停稳滑跑速度 ≤25 km/h）。成功奖励 5 绿宝石，驱动零件解锁。
- **回放**（`FlightReplay`，P 键）：机体重演而非纯相机秀（物理冻结，把真实机体按录制位姿摆放）。分镜 SHOT：ORBIT / COCKPIT / CHASE / TOPDOWN / WING，单镜头 3 s、末镜头最短 1.5 s、过渡 0.6 s；叠加幽灵轨迹条带（青蓝渐变，半宽 0.28 m）。
- **成就数据源**：起飞边沿 `aircraft_took_off`、离地高度里程碑每 20 m、空中里程每 100 m（对应"展翅高飞 / 冲上云霄 / 空中漫游"）。
