# Block Planet 地图选择器与中国地貌微缩沙盘设计文档

> 项目：Block Planet  
模块：地图选择器（Map Selector）、地标系统（Landmark System）、UI/交互
目标：在 128km × 128km 的体素世界中，将中国地貌（三山五岳、长江黄河、三峡）以多级缩放（Zoom Levels）和互动沙盘的形式完美呈现在地图选择器中。


## 1. 设计理念与视觉层级

由于游戏世界是缩比的，地图选择器不能直接塞入 1:1 的真实比例地形。我们采用 “多级缩放 + 空间投影 + 体素沙盘渲染” 的体验流，让玩家通过缩放地球，逐步聚焦到中国区微缩景观。

地图选择器的体验分为三个阶段：太空视角（God View） → 洲际视角（Continental View） → 沙盘视角（Sandbox View）。

### 1.1 第一级：太空视角（上帝视角）

- 视觉表现：一个缓慢自转的 3D 地球仪，贴图采用写实与卡通结合的地球贴图。
- 交互：玩家可以拖动旋转地球，用滚轮或双指捏合放大。大洲（如亚洲、欧洲）上方有悬浮的标签。

### 1.2 第二级：洲际视角（聚焦中国区）

- 视觉表现：当玩家放大亚洲区域时，真实贴图淡出，表面材质逐渐过渡为体素风格的浮雕地形（能看出山脉的起伏和河流的走向）。
- 标志物浮现：在这个层级，能看到用特殊光效勾勒出的黄河“几”字形、长江的蜿蜒曲线。
- 地标图钉（Pins）：地图上浮现出“三山五岳”、“三峡”的专属图标（如山峰图标、大坝图标）。
### 
### 1.3 第三级：沙盘视角（微缩模型直现）


- 视觉表现：当镜头极度拉近中国区时，地球曲率消失，视图变为一个俯视/等距视角的 3D 沙盘。

- 微缩模型：在这个视角下，10km × 10km 的中国区完全显现。黄河的黄土色、三峡的险峻峡谷、华山的垂直峭壁、泰山的阶梯，都变成可以随意查看的立体微缩景观。

## 2. 地标（Landmark）具象化呈现
为了兼顾儿童玩家的易读性与地理科普，地图上的地标必须做“奇观化”的 Icon 和交互特效。

-动态水流发光：在地球仪上，长江用浅蓝色流动的光带表示，黄河用土黄色流动的光带表示。

地标卡片（Hover/Click）：

- 鼠标悬停或手指点击“三峡”图标时，弹出半透明的全息面板。

- 显示该地标的三维微缩模型（局部）。

- 科普文字：“长江三峡，瞿塘峡、巫峡、西陵峡的总称。”

- 【快速旅行】按钮：点击后直接降落在三峡附近的机场，进入飞行或徒步模式。

动物/特色图标：在长江放一个中华鲟的 Q 版图标，在黄河放一个黄河鲤鱼的图标，点击直接跳转到对应的钓鱼玩法图鉴。

## 3. Godot 4.6 技术实现方案

### 3.1 3D 地球仪渲染

建立一个 Node3D 作为地图中心。

添加 MeshInstance3D，使用 SphereMesh（球体网格）。

编写一个 ShaderMaterial，使用地球漫反射贴图和法线贴图。

使用 Camera3D 配合 OrbitCamera 脚本（或 SpringArm3D），实现相机的环绕旋转和滚轮缩放。

### 3.2 经纬度到游戏坐标的映射（核心算法）

游戏是 128km × 128km 的平面，地球是球体，必须写一个坐标映射函数。
建立一张“伪经纬度”表。将游戏世界的 128km 对应到地球的某个区域。

坐标映射公式（伪代码）：

```gdscript
# 真实经纬度 (Lat, Lon) 映射到 游戏世界坐标 (X, Z)
func lat_lon_to_world(lat: float, lon: float) -> Vector3:
    var normalized_x = (lon - MIN_LON) / (MAX_LON - MIN_LON)
    var normalized_z = (MAX_LAT - lat) / (MAX_LAT - MIN_LAT)
    return Vector3(normalized_x * 128000, 0, normalized_z * 128000)
```

### 3.3 地标 Pin 与 2D/3D 混合 UI
不建议在 3D 地球表面直接贴 2D 控件（容易变形）。

使用 Godot 的 Camera3D.unproject_position() 方法，把 3D 空间中的地标坐标转换成屏幕的 2D 坐标。

用一个 Control 节点（CanvasLayer）作为全屏遮罩，在这个节点里动态生成地标图标，每帧更新它们的屏幕位置。

### 3.4 缩放过渡效果（LOD）

- 当相机距离 > 500 单位时：显示纯 3D 地球（高模平滑球体）。
- 当相机拉近到中国区时：球体淡出，预先拼好的 128km “3D 地形高度图（Heightmap）”淡入。
- 利用 Tween 节点做两个视图之间的透明度过渡。

## 4. 给 AI 智能体的开发指令 (Checklist)
 请将以下内容添加至开发任务书的【地图选择器与 UI 系统】模块，并逐一实现：

□ 实现 MapSelectorUI，包含 3D 地球仪模型（SphereMesh + 地球贴图 Shader）。
□ 开发 OrbitCamera 脚本，支持鼠标右键/触屏拖动旋转地球，滚轮/双指捏合缩放。
□ 编写坐标映射工具 GeoProjection.gd，提供 lat_lon_to_world() 和 world_to_lat_lon() 接口，用于地标锚点。
□ 创建 LandmarkPin.tscn。每帧通过 camera.unproject_position() 将 3D 世界中的地标坐标（如三峡、华山）转换为屏幕坐标，在 CanvasLayer 中绘制图标。
□ 当相机缩放值（camera.size 或 position.z）达到阈值时，使用 Tween 将地球球体平滑过渡为 3D 微缩沙盘（可通过切换 LOD 节点或直接移动相机进入实体世界实现）。
□ 地标点击事件：点击 Pin 弹出信息面板，点击【出发】按钮后，将玩家角色生成在目标地标的安全坐标点，并关闭地图选择器。
□ 在长江与黄河的河道 Mesh 上应用 UV 滚动的发光 Shader，模拟水流。
